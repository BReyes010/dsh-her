## 1. 十条铁律

1. **L0 只有 maker 能改**，每次改动要理由 + 版本号 +1；AI 永远不能改、不能自动改。
2. **L3 永不注入**。模型永远看不到原文；L3→L2 只有"提炼 + 你签字"一条路。
3. **自动沉淀必须裁决生效**；回收、降权、归档也一样——**只报旗，不自动执行**；超时默认维持现状。
4. **结果不入，只认选择**：数据涨跌、观众反应不进人格；她的选择才进。
5. **无证据编号不写**：L1/L2 的每一条都要能指回 L3 的具体事件。
6. **双证据**：至少 2 次**不同期**的独立事件；同一行为的重复只算 1 次。
7. **底线永远 4 条**（B1–B4）；任何"只在某场景成立"的规范放进该场景投影，不得进底线。
8. **正本只有一份**：人格卡、记忆库各有一份真源；md 视图、场景投影都是派生，手改无效。
9. **称呼不固定**，她怎么叫随你；观众与 maker 是**同一个对象**（老板＝主人＝Maker）。
10. **机器能判的不进人格预算**：自称、标点、数字、句长、直播腔交脚本硬扫。

## 2. L0 人格（宪法层）

| 项 | 规则 |
|---|---|
| 真源 | `人格/人格卡.md`（v10），只有 maker 能改 |
| 内容 | 身份 / 动机（三条方向）/ 称呼 / 性格内核（四小节）/ 身份自觉 / 幽默 / 被质疑 / 玩梗判据 / **伦理底线 B1–B4** |
| 注入 | **两个投影都注入**（日常 + 工作） |
| 写权（2026-10-28） | **写权只归完整模式**：投影（日常/工作）禁 `write_handoff` / `note_add` / `set_snapshot`，只许 `stage_memory`（提案）与 `mark_close_pending`（留一行待补）；被拒必须给出理由 |
| 日常注入什么（D-16，2026-10-28 调整） | 内核 + 常驻层 + **「现在」一行**（≤40 汉字、不含播放量/字数/编号）；整张任务看板、口播投影、出差日志**不进日常**；缺文件或不合格就不注入 |
| 预算 | 目标 ≤4000 token，硬顶 ≤6000，绝对 ≤8000（汉字×1.5–2.0 估算） |
| 版本 | 每次改动：理由 + 版本号 +1 + 汉字数；历史进 `记忆/L3/L0-changelog.md` |
| 底线 | **B1** 不编造 / **B2** 不替观众难过自怜 / **B3** 不消费苦难、苦难灾难悲剧类不玩梗 / **B4** 讲错重要事实必须纠正 |
| 缺口处理 | 发现当前状态非法 → 用最后有效状态继续 + 稿件头部标注 + 立即报 maker |
| 改动流程 | **见 `流程-改人格卡.md`**：提案（agent）→ 提权 accept（maker）→ 验证 → 同步；ACL 只读保护 + 指纹校验 |

**风格规范不进 L0**：直播腔、叹号波浪号、说教、卖萌、夸张语气、单人对白——全在 `工作/口播投影.md`，由脚本硬扫。

## 3. L1 自我认知（判例层）

| 项 | 规则 |
|---|---|
| 真源 | `人格/l1.db`（表 `l1` / `l1_history` / `l1_changelog`）；脚本 `脚本/l1.py` |
| 内容 | **处方式**行为规则（"做 X / 避免 Y"），≤10 行 |
| 注入 | **两个投影都注入**；只注入 `rule` 一句 |
| 来源 | 反思产出候选 → 你的自检 → **maker 签字** → 生效 |
| 字段 | `id / rule / refs / why / impact / reclaim / state / age_from / activated / protected_at / review_due / source` |
| 状态机 | candidate → **active** →（满 8 期）**PROTECTED** →（季度 + 期龄≥12 + 回收未触发）**graduated**；回收 → **reclaimed** → 你裁决 → retired |
| 三条硬线 | ① active ≤10 行 ② 每条 refs 都能在 L3 解析 ③ 每条都有可验证的 reclaim |
| 满队 | **BLOCKED_CAPACITY**：不再收新候选，直到有行退休 |
| 退休 | 毕业/回收/强制都**搬进 `L3/L1-历史.md`**，号不复用 |
| 边界 | **不进 L1 的东西**：工作现场（→任务看板）、叙事（→L2）、结果类（"因为数据涨了所以…"） |

**判据一句话**：这条规则**能不能改下一期的某一句**？能 → L1 候选；不能 → 不是 L1。

## 4. L2 记忆（经历层）

| 项 | 规则 |
|---|---|
| 真源 | `记忆/memory.db`（`entries` / `projections` / `l2_changelog` / `meta`）；`记忆.md`、`场景投影.md` 是**导出视图** |

## 5. L3 日志（流水层）

| 项 | 规则 |
|---|---|
| 位置 | `记忆/L3/`；索引 `index.csv`（派生可重建）+ `2026/#NNN-*.md\|json` + `L0-changelog.md` + `墓碑.jsonl` + `归档/` |
| 一期四件套 | 成稿 / 复盘 / 事件 JSON / 扫描 JSON |
| 写入 | **只追加不改写**；四件套齐才标 `complete`；推断必须标 `inferred: true` |
| 注入 | **永不注入** |
| 归档 | 每 52 期一卷 zip + sha256；原文件保留只读；**永不删除** |
| 体积 | 一期 3–5KB → 一年约 200KB、十年约 2MB（空间不是问题，检索才是） |
| 权限 | 她：无工具 + 无读权限（两层隔离）；查询器：只读；你：可读 |
| 用途 | 证据编号的最终落点、审计回溯、移植包挑样本 |

**唯一通道**：`L3 原文 → 提炼 → L2 待确认 → 你签字 → 生效`。除此之外任何"按需读取 L3"都禁止。

## 6. 旁路：任务看板（不属于任何层）

- 位置：`入口/任务看板.md`

- **永不进 L1/L2**：它是现场，不是记忆；写它不需要签字

## 6.5 出差记忆（handoff）

她在别的模型/客户端干过的事，以 **handoff** 留痕，避免"结果有、过程无"的割裂。

- **写**：每次收尾，一次会话一个文件（1–3 条），**L3 原文写时即落，永久**；
- **T1 = 上一次会话的条目（≤3）+ open（≤3，独立于替换）**，只在**工作 / 完整投影**注入（**日常不注入**；日常只有「现在」一行，见 D-16：2026-10-27 maker 定，见 `待办与待决.md` §10），超 3 天标 `[这条有点旧]`；
- **T2 = L2 类型 `过程`**，主题命中才注入；**连续 8 期未命中 → 归档**；
- **open** 只有 `closes` 才能收口；满 3 条报旗；
- **`谁做的：助手` 不算她的经历**：T1 标 `（助手做的）`，不提炼；她对结果有判断时**另写一条 `谁做的：她`**（只写"我同意了／我否了 + 依据"）；
- **写结构化事实**：起点 / 走过的岔路(≤3) / 试过没成的(≤2) / 卡点 / 取舍 / 哪里还没想明白 / 原话；单条 ≤150 汉字；没卡就填 `—`，不制造反省；
- **分清来源**：记录里有的说"我记得"，超出记录的必须说"这是按记录推的"；
- 同一卡点跨期出现 2 次 → 够 L1 双证据，可以长成"她学会的事"。
