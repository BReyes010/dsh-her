## 三分钟上手

0. **要她说话** → 导入 `启动包/` 下的一个包（收尾自动刷新）；日常包里有一块「你现在在哪一步」，只有一行、只用于被问到时回答：`完整模式.txt`=整个角色 / `工作模式.txt`=写稿投影 / `日常模式.txt`=聊天投影。三者区别与用法见 `索引-三种加载方式.md`
1. **要写稿** → 读 `工作/SKILL.md`，按流程：`人格/人格卡.md` + `python 脚本/l1.py inject` + `工作/口播投影.md` + `工作/口播技术规范.md` + 记忆检索结果。
2. **要闲聊** → 注入 `人格/人格卡.md` + `python 脚本/l1.py inject`（日常投影），不加口播样本、不加句长限制。
3. **检索记忆** → `python 脚本/memory_lookup.py --topic "..."`（常驻层自动带出，关键词层按主题命中）。
4. **扫一遍成稿** → `python 脚本/scan.py 稿件.md --json 记忆/L3/<年>/#NNN-scan.json`（违规会列出，退出码 1 = 有违规）。
5. **写回记忆** → `python 脚本/memory_db.py add --title "..." --category "..." --body "..."`（进**待确认区**）→ `python 脚本/memory_db.py export` 刷新视图 → maker 过目后才启用。
6. **收尾** → `python 脚本/workbench.py render`：渲染任务看板 **+ 刷新启动包 + 校验 L3 索引**（md 手改会被拦；`--no-pack` 只渲染不刷包，`--no-check` 跳过 L3 校验）。
7. **建立新场景** → 在 `memory.db` 的 `projections` 表登记（注入块/加强/放宽），export 出视图，跑一遍跨场景一致性检查。

## 四条铁律

1. **人格卡只有 maker 能改**（理由 + 版本号 +1）；AI 永远不能改，也永远不能自动变更。
2. **自动沉淀必须裁决生效**；回收也一样——报旗，不自动执行。
3. **结果不入，只认选择**：数据涨跌不进人格，她的选择才进。
4. **记忆库是真源，md 是视图**：手改 md 无效；改库后必须 export。底线永远是 B1–B4，场景规范不进底线。
