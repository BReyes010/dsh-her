# 用法：触发词（载入 / 出差 / 新建角色）

> 三句话，对应三个动作。**说人话就行，不用记命令。**

---

## 一、载入角色：「<卡> <模式>」

```
{角色名} 工作模式
{角色名} 完整
dafeiyu 日常
模板 工作
```

**解析顺序**（`脚本/load.py` 实现）：

| 步骤 | 规则 |
|---|---|
| 1 | 卡 id 全等（`dafeiyu`） |
| 2 | 别名全等（现役卡别名：`{角色名} / {角色名} / 鱼`；模板：`模板 / template`） |
| 3 | 名字全等 |
| 4 | 名字 / 别名 / id **包含** |
| 命中多个 | **现役卡优先**；仍多个就报歧义，要求用 id |

**模式**：只认 `日常 / 工作 / 完整`，**缺省 = 日常**。

对 AI 的规则（写进会话开头即可）：

> 用户说「<卡> <模式>」时，先跑 `python 脚本\load.py "<那句原话>"`，
> 把返回的包当成你的身份与记忆；包外的东西一律说"这段我没记"。

对**没有工具**的客户端（千问等）：这句话它接不住，得走下面的出差包。

---

## 二、出差：「去 <目的地> 出差吧」

```
去千问出差吧
出差吧
去 Claude 出差
```

带**任务**说，才会真的生成：

```
python 脚本\load.py "去千问出差吧" --task "把第 2 期稿改成更适合念的版本" --to 千问
```

生成 `出差包/出差-<卡>-<时间>.md`，里面四块：

| 块 | 内容 |
|---|---|
| ① 顶部 | 给外部客户端的用法：你只能靠这份包、包里没有的不许编 |
| ② 角色 | 按模式取（**出差缺省 = 工作**；可 `完整`/`日常`） |
| ③ 任务 | 这次要它做什么 |
| ④ **回程** | 结束时要它交回的模板（主题/谁做的/起点/卡点/岔路/死路/取舍/没想明白/原话/open/closes/留下） |

**回程怎么收**：它交回那段贴回来 → 我们照常写进 `handoff`（L3），下次开场就注入。
**原话那一条不许改写**——改写成结论，等于把发生过的事磨平一次。

---

## 三、新建角色：说一句就行

```
新建一个角色，叫阿布
```

允许。做法（我执行，你只需点头）：

```powershell
python 脚本\new_card.py --id abu --name "阿布" --from dafeiyu-template
```

- `--from dafeiyu-template` → 从模板复制一份（内核、场景、卡声明），换成新 id/名字；
- `--kit new`（默认）→ 同时建空记忆套件 `memory/abu/`（db + L3 骨架）；
- 建完**立刻可用**：`阿布 日常模式`。

**建完你要做的**：改 `cards/abu/persona.md`（那是"他是谁"），别的不用动。
**不要**直接改 `memory/abu/memory.db`——记忆走脚本、要签字。

界面上（插件 P1）会是设置页里的一个「+ 新建角色」按钮，调的是同一条命令。

---

## 四、三句话的速查

| 你说 | 发生什么 |
|---|---|
| `{角色名} 工作模式` | 打印工作模式的完整注入包（含口播技能 + 通用/工作记忆） |
| `去千问出差吧` + 任务 | 生成一份自包含的出差包，附回程模板 |
| `新建一个角色，叫阿布` | 从模板建卡 + 空套件，建完可立即载入 |
| `load.py --list` | 列出所有卡、场景、可用模式 |

---

## 五、边界（三件事都不许自动做）

1. **不自动改人格卡**——只有 maker 能改，改走 `l0_apply.py` 提权。
2. **不自动写记忆**——她的提案进待确认区，你签字才生效。
3. **出差包不许带 L3**——原始日志永不外发；出差包只带"能独立开工的那一份"。
