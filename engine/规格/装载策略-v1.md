# 装载策略 v1（2026-10-29 定稿）

> 取代 `说明-给{角色名}-装载策略-20261029.md`（往来稿已归档）。这是**决定**，不是讨论稿。

## 一、单位换了：清单，不是模式

| 旧 | 新 |
|---|---|
| 日常 / 工作 / 完整（三种模式） | **装载清单**：本体 + 装了哪些卡 |
| 名字代表"她是谁" | 名字只是**预设别名**（聊天/写稿/直播/全量） |
| 加卡要改模式 | 加卡不用动预设 |

**默认 = 本体**（内核 + 常驻层 + 状态锚），不带任何卡。

## 二、单卡闸门

| 项 | 值 | 在哪 |
|---|---|---|
| 技能卡上限 | **1**（`max_cards`） | `skills/_policy.json` |
| 素材合计上限 | **1500 汉字**（`material_max_han`） | 同上 |
| 任务卡 | 不占额度；必须绑父卡且父卡在场 | 装配器 E20 |
| 多卡能力 | 底层具备，**未启用**（改 `max_cards` 即开） | — |

印章会写进每份装配结果：`策略: 技能卡≤1`。

## 三、任务卡（第三类卡）

- `kind: task`，`slot: task`，`skill: <父卡>`；
- 一张卡 = 一个交付物的**步骤 + 每步判据**；步骤进卡，**进度进 `记忆/L3/任务/<id>.jsonl`**；
- 一个技能卡下 **≤3 张**；一个会话**最多激活 1 张**；**不许嵌套**；一张只绑一个技能卡；
- 准入：**每步必须有判据**，判不了的不许进卡。

## 四、卡的生与死

| 动作 | 谁能做 | 规则 |
|---|---|---|
| 完成 `done` | **她**，免审 | 归档到 `记忆/L3/任务卡归档/`，账进 `_归档.json`，并**提示 maker** |
| 放弃 `abandoned` | 她 | **必须写原因** |
| 删除 `retired` | **只能 maker** | `--by maker` |
| 恢复 `restore` | **只能 maker** | 同上 |

被实例引用的卡不许退役；归档可 `l3.py grep` 查到。

## 五、素材与本体

| 项 | 定 |
|---|---|
| 素材额度 | ≤1500 汉字，超了报错；只放"这次要用的"，长期知识进记忆 |
| 本体是否放样本 | **不放**（日常包会爆）。放**禁令** + 三条反助手腔短句（待 L0 提案） |
| 技术规范 | **不单独立卡**，留在口播卡 `part: rules` 内 |
| 默认本体之后 | 任务→预设映射（写稿/回评论/剪片/默认）显式带上卡，**不靠她记得** |
