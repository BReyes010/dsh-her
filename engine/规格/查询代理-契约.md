# 规格：查询代理（l3q）

> 状态：**契约已定，实现未开始**（2026-10-27 夜）
> 定案见 `待办与待决.md` 第 13–18 条。

---

## 一、它是什么

一个**独立的进程**（MCP 服务或 CLI 壳），替角色查"发生过的事"。
它**不是**她的记忆，也不是给用户用的搜索框——它是她和日志之间的中间人。

```
用户 ──问"还记得那次壳的事吗"──▶ {角色名}（her-host）
                                    │
                                    ├─ 先查 L2（她自己的记忆）→ 没有
                                    │
                                    ├─ recall(问题原文) ──▶ l3q
                                    │                        ├ 规则快筛
                                    │                        ├ 小模型规划（模糊时）
                                    │                        ├ 执行检索（复用 l3.py）
                                    │                        └ 审计落盘
                                    ◀── 结构化片段 ─────────┘
                                    │
用户 ◀── {角色名}用自己的话回（可引用、可只说大概）──┘
```

**硬规矩**：l3q **没有任何对用户的通道**。它只跟{角色名}说话，且只说"素材"，不说"答案"。

## 二、接口契约

### 请求（{角色名} → l3q）

```json
{
  "question": "用户原话，尽量别改写",
  "hints": {
    "when": "上周 / 10 月中 / 记不清",
    "keywords": ["壳", "授权"],
    "topic": "第 2 期"
  },
  "budget": 3,
  "session_id": "s-20261027-2030"
}
```

- `hints` 里任何一项都可以缺；**缺了就是缺了，不许 l3q 自己补**；
- `budget` 默认 3（探针次数），由调用方给，l3q 不得超用；
- `session_id` 只用于审计串联。

### 响应（l3q → {角色名}）

```json
{
  "status": "found | none | need_more",
  "fragments": [
    {
      "id": "2026/#002-复盘",
      "date": "2026-10-27",
      "topic": "壳与账",
      "excerpt": "……（原文，≤300 字）",
      "source": "L3 日志原文",
      "lines": "12-19"
    }
  ],
  "probes": [
    {"n": 1, "when": "10 月中", "keywords": ["壳"], "hits": 0},
    {"n": 2, "when": "10 月", "keywords": ["壳", "账"], "hits": 3}
  ],
  "probe_detail": [            // 与 probes 同构；审计里也写一份，用来回答"她为什么第三次才找到"
    {"n": 1, "when": "10 月中", "kw": ["壳"], "hits": 0},
    {"n": 2, "when": "10 月", "kw": ["壳", "账"], "hits": 3}
  ],
  "note": "第一次窗太窄，第二次放宽才命中"
}
```

- `status` 三档：`found`（有片段）、`none`（日志里确实没有）、`need_more`（信息不够，建议先问用户）；
- `fragments` **最多 3 条**，每条 `excerpt` ≤300 字；**永不返回全文**；
- `probes` 是给审计和"她怎么找到的"用的，不回给用户。

### 观点类豁免（2026-10-28 加）

**不是"发生过的事"，一律不查**：`该不该 / 要不要 / 怎么看 / 觉得 / 你认为 / 值不值 / 对不对 / 建议 / 意见`。
命中即返回 `{"status":"need_more","note":"这是观点/判断类问题，不是「发生过的事」——不查日志，直接按自己想法答"}`，
**探针次数为 0**，提示语也不再说"问一个具体线索"。

### 检索口径（2026-10-28 加）

- 时间与关键词齐全 → 规则直查，**不调模型**；
- 中文长串（>4 字）自动拆成相邻二字，`l3.py grep --any`（任一命中即可）——
  避免"措辞不同"被判成"没发生过"；
- 关键词 >1 个时用 OR；单个关键词时仍用精确匹配。

### 错误

| 情况 | 返回 |
|---|---|
| 时间说法认不出 | `{"status":"need_more","note":"没听懂时间：xxx"}` |
| 关键词为空且时间也为空 | `{"status":"need_more","note":"需要至少一个线索"}` |
| 索引/文件损坏 | `{"status":"none","note":"日志索引异常：<原因>"}`（**不许假装查过**） |

## 三、规划器：混合（已定）

| 层 | 做什么 | 成本 |
|---|---|---|
| **规则快筛** | 没有"回忆类"信号（还记得/之前/上次/那时候/那件事）→ 直接 `need_more` 或不调用 | 0 |
| **规则预判** | 有时间词 + 有 ≥1 关键词 → 直接出探针计划，**不调模型** | 0 |
| **小模型** | 只有"模糊"（没时间 / 没关键词 / 多义）才调：输出探针计划或 `need_more` | 1 次调用 |

模型输出必须是 JSON，且**必须有"不查"这个出口**。判定为 `need_more` 时，给她一句可直接问用户的话（例如"大概是哪个月？跟稿子有关还是跟素材有关？"）。

---

## 四、探针包：默认 3 次

| 次 | 策略 |
|---|---|
| 1 | **宽**：大时间窗（月份级）+ 单关键词 |
| 2 | **窄**：加第二个关键词 / 换同义说法 / 缩到周级 |
| 3 | **换角度**：用主题名、期号、事件名再试 |

用完 3 次仍 `none` → 不硬拦，转成"问用户要线索"。**探针次数记在审计里，可事后看"她为什么没找到"。**

## 五、审计（不可删）

`记忆/L3/_查询审计.jsonl`，一行一次调用：

```json
{"ts":"2026-10-27T20:31:02","session":"s-...","question_hash":"9f2c","when":"上周",
 "keywords":["壳"],"status":"found","hits":2,"ids":["2026/#002-复盘"],"probes":2,"ms":180}
```

- **决定不查的那次也要记**（`status:"skipped"` + 规则/模型给的 `reason`）；
- 不记用户原话明文（只记 hash 与前 20 字），避免审计本身变成 L3 的副本；
- 不提供删除接口。

## 六、失败用例清单（先写测试，再写实现）

| # | 场景 | 期望 |
|---|---|---|
| F1 | 用户问"你觉得这事该不该做"（观点，不是回忆） | `need_more`，**不查** |
| F2 | 用户说"上次那个"（无时间无关键词） | `need_more` + 一句追问 |
| F3 | 有时间但日志里确实没有 | `none` + "这段时间没记录"，**不许编** |
| F4 | 时间说法认不出（"那个啥时候"） | `need_more` + 列出支持的写法 |
| F5 | 关键词是 L2 已有的（如"{角色名}"） | 应先命中 L2，**不调 l3q**（由{角色名}自己判断） |
| F6 | 一次 3 探针全空 | `none` + 建议问用户，**不展开第 4 次** |
| F7 | 命中 >3 条 | 只回 3 条 + note 说明"还有 N 条" |
| F8 | 审计文件不可写 | **拒绝查询**（不许查了不记账） |
| F9 | L3 索引损坏（`l3.py check` 有错） | `none` + 报异常，**不返回半份结果** |
| F10 | {角色名}把片段原文直接倒给用户 | 契约层拦不住 → 靠 `说明-给{角色名}` 的规矩 + 事后抽查 |

## 七、和现有铁律的关系

`四层规范合集` / `L3-规范` 现在写的是「**L3 永不暴露**」。本契约把它改成：

> **L3 不注入、不批量导出、不写回记忆**；只允许**单次、按需、带审计的片段检索**，且检索只能由 l3q 执行、只能回给{角色名}。

**这是规则级变更**，落盘要走 L0 提案（`l0_apply.py`）+ 你提权。
