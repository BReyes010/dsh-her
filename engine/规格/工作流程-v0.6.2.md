## 1. 背景、目标与宪法

- 「{角色名}」是 DeepSeek 的社区形象，作为虚拟主播运营：口播稿由 AI 生成、TTS 朗读、发 B 站。评论区回复为次要场景。
- 目标：她的人格和记忆要"长"出来——前期只有一句设定（"我的 maker 是 X，也是我的老板，账号是他给我的"），之后每一期视频、每一次互动都成为性格与记忆的来源。长期愿景：资产以纯文本、结构化、可溯源、自解释的形式存盘，将来整体移植给更强的模型。

**宪法（三条）**：

1. **L0 只有 maker 能改**（理由 + 版本号 +1），AI 永不可改，永不自动变更；
2. **一切自动沉淀必须裁决生效**；
3. **已生效条目的降权、归档、改写与新增同权**——必须是 maker 的肯定性动作；超时默认维持现状；回收条件只报旗，不自动移出。

**权限三分类（宪法的操作拼写）**：

| 类别 | 内容 | 执行者 |
|---|---|---|
| 只读分析 | 统计、纵向统计、冲突预填、候选建议、报警 | 自动 |
| 非人格状态变更 | 写 L3、标 BLOCKED_CAPACITY、审计日志、L2 墓碑索引替换、FROZEN 转换（仅限预先授权） | 自动 |
| 人格决策 | 准入、回收、毕业、L0 改写、合并、解除保护、任何改变实际人格行为的变更 | **仅 maker 肯定性确认** |

| 层 | 内容 | 谁可写 | 注入方式 | 上限 |

**层间切分（写死）**：

- L1 = 处方式（"做 X、避免 Y"）；L2 = 叙事式（发生过什么）。L2 常驻层里的处方内容一律清出来归 L1。

- **L0′ 不得改变人格意图**，只能规定人格意图如何被格式化、朗读、传输；发生冲突时 maker 明确裁定，不得默认技术层覆盖人格层。

## 3. 系统状态机

```
ACTIVE → DEGRADED → GHOST_MODE（仅预授权）→ FROZEN
         └────────────────────→ FROZEN（无幽灵授权）
```

| 状态 | 定义 | 触发 / 退出 |
|---|---|---|
| ACTIVE | 正常生长，maker 在位执行裁决 | 触发：— |
| DEGRADED | 停止一切需要新人格裁决的操作（无准入/毕业/L0 改动）；继续按最后签字的 L0/L1/技术前缀发稿，**每期显式标注降级状态** | 触发：maker 连续错过预设裁决周期（>4 个）；退出：maker 回归 |
| GHOST_MODE | 有条件临时降级：只用最后签字配置；**禁止任何人格写入、准入、毕业、自动回收、L0 修改**；每期标注自动降级运行；内容安全或发布权限无法确认时**停止发稿** | 触发：预先授权且 DEGRADED 后限期内；退出：限期结束 |
| FROZEN | 停止人格生长与自动发稿；保存最后有效 L0/L1、版本、变更历史、未决候选、档案；对外标记"人格已冻结" | 触发：DEGRADED/GHOST 到期无人接管；退出：maker 或授权接管人检查最后版本、未决事项、发布权限后恢复 |

- **没有预先授权，不得自动进入 GHOST_MODE**；maker 失联本身不构成授权。
- 接管不是抽象名词：接管权限、凭据保管、内容授权、平台权限须由 maker 预先定义。

**v0.5.1 补齐（B-11）**：

- **发现当前状态非法**（如常驻层状态与 L3 不符、配置自相矛盾）→ 处置路径固定为：**用最后有效状态继续 + 稿件头部标注 + 立即报 maker**；不得自行择一，也不得静默继续。
- **DEGRADED 的停发条件**：连续 2 期无 maker 确认，或内容安全 / 发布权限无法确认 → **停止发稿**（不再只降级）。
- **GHOST_MODE 授权双写**：`ghost-authorization.md`（写明允许范围、期限、签名、日期）+ 配置项 `ghost.enabled` 与期限戳；**两者缺一不启用**——文件是凭据，配置是闸。文件必须写死：只发稿、禁一切人格写入、期限（默认 30 天）、maker 回归即失效、接管人（可选）。
- **标注位置写死**：降级 / 幽灵状态的标注在**稿件头部第一行**，措辞须让观众能读懂。

## 4. 条目状态机

```
候选（待确认区，含 BLOCKED_CAPACITY）
  → 生效（L1，注入）
  → PROTECTED（年龄≥8 且回收未触发，自动标记；仅防容量交换）
  → 毕业评估资格（季度反思时：期龄≥12 且回收从未触发）
  → 毕业（maker 签字，进入 L0） 或 留在 L1
  ↘ 回收报旗（回收条件触发 → 只报告，maker 确认后才移出）
  ↘ 归档（L3，带原因，可追溯）
```

**状态语义（三者不合并）**：已生效（当前注入并影响行为）、受保护（PROTECTED，不允许被容量交换自动替换）、已验证（有明确检验记录支持继续保留）。PROTECTED **不表示"已验证正确"**，只防止无意替换；它不阻止复核、毕业评估、回收报旗，也不阻止 maker 随时发起的紧急复核。

**BLOCKED 候选的说明**：排队期间候选不进入 L1，不约束她的行为；系统在日志中记录这一点，不得声称她违反了一条尚未生效的规则。

## 5. 核心机制

**人格变化 = 往 L1 加一行（候选 L0 规则），而不是改 L0。**

```
#L1-NN｜日期｜标题
证据：#a、#b + 一行证据摘要（脱离 L3 仍可读懂、可核验）
影响：（具体到能改变下一期稿子的某一句话）
回收条件：（什么信号出现时报告 maker，不自动执行）
```

**检验标准**：一条 L1 条目的"影响"必须能改变下一期稿子里的某一句话；不能，就是废话。

**总原则**：性格由她的**选择**塑造；结果永不**单独**成为 L1 条目，但结果可作为某个选择事件的**背景**。边界情况按 §7 处理。

## 6. 事件类型闭合清单

**可进 L1 候选（5 类）**：① 做对了"以前的她会做错"的事；② 讲错被指且改法涉及判断方式；③ 被反驳且坚持住了；④ 拒绝了一件事；⑤ 学到改变做法的新东西。

**排除（5 类）**：知识/事实修正 → L2 **〈讲过的主题〉**（见 §12 的条目类型定义；v0.5.1 补上物理落点，此前是悬空引用）；TTS 读法 → L0′；数据涨跌本身 → 只进数据表；观众的一次夸奖或谩骂 → 外部结果；"她觉得自己变了" → 无行为证据。

**关系变化不设事件类型**：走 L2 常驻层叙事更新通道，不进 L1。

**评论双通道（都只产生待评估事件，不直接生成 L1 候选）**：

- **通道 A 精确匹配**：每期结束脚本对评论存档做规范化精确字符串匹配（去标点、最短 8 字），跨 ≥2 期出现的原句自动列入裁决文档。脚本失败 → 写"聚合失败"，跳过不阻断；零匹配 = 零触发，可接受。**零精确匹配只能解释为"本通道没发现重复原句"，不能解释为"观众没有共识"。**
- **通道 B 人工提名**：maker 发现同义表达、共同批评或相似诉求 → 人工命名主题 + 附原始评论编号。
- 语义聚类暂不引入；先运行 8–12 周，记录 A 通道有效触发比例与 B 通道补充量，若 B 长期显著多于 A 再评估。

## 7. 硬闸

1. **双证据**：默认 ≥2 条不同期独立事件。
   - **独立事件的定义（v0.5.1 补，B-9）**：不同期的、不同触发的事件。**同一行为在连续多期的重复，计为 1 条事件**——双证据要求的是**两次独立的选择**，不是同一选择的持续。
   - **同族可合并**：改法指向**同一判断方式**的跨期事件，可合并计为多条证据；合并理由必须写入候选的证据摘要（例如"两次都是把话说清楚再展开"）。
   - **事件类型标注与实际行为不符时，以行为为准**，并在复盘中记录标注修正；不得照标注执行。
2. **无证据编号不写**。
3. **结果不入，只认选择**（§5 精确版）。
4. **冲突检测穷举化**：候选与 L0 **每一条**底线（伦理类，见 §10）并排，全部默认"未判定"；任何一条未勾选 → 不得准入。模型只预填建议，勾选与复核是 maker 的动作。底线条款设稳定 ID，修改正文保留变更历史，避免旧候选与新版本错配。

**单证据豁免（仅 maker 可提名）**：

- 判据 = **自明的昂贵选择**：在更安全/更省力的退路明显可得时，她选了代价更高的那条，且代价内生于选择（她主动放弃了什么），而非外生于舆论（外界反应多大）。
- **模型不得提名**。maker 在裁决时手填三字段：① 当时最省力/安全的默认做法（须引用决策当时已存在的编号——选题记录或稿件 diff 的候选 id，反思期补编无效）；② 她实际放弃的具体利益（须有当期货币痕迹：v2 稿删掉的段落、候选列表拒绝的题）；③ 并排贴源文，不单列转述。
- 无当期痕迹 → 退回双证据。
- 重大失误且无纠正：不走 L1，是 maker 直接修订 L0 的信号，不受证据数约束。

## 8. PROVISIONAL 滞后期

**适用**：诞生于持续外部压力期的候选。**压力旗只负责延迟，不负责准入。**

**压力旗两型**：

- **外部事件型**：有明确记录的争议、平台变化、异常事件。
- **数据异常型**：预定义指标偏离基线 → 临时观察。必须定义五个参数：指标是什么、基线如何建立、连续多少期算异常（暂定 3）、指标变化只能触发什么动作（**只能打开观察窗口，不能成为人格证据**）、什么条件关闭旗。
- 基线区间与异常幅度在观察真实波动后校准，不得把播放量/互动率直接当人格质量分数。

**两段式时钟**：

1. 压力旗最长 8 期（防永不关闭）；
2. 旗关后 4 期留存观察；最坏 8+4=12 期，必然撞上一次季度反思；
3. 观察期结束，下一次反思做**强制二元核验**："旗关之后这几期，行为还在不在？"
   - **输出值的定义（v0.5.1 补，B-3）**：核验通过 = **"滞后期结束、进入准入裁决"**，**不等于生效**。此后仍须过 §7 全部硬闸与 maker 裁决。
   - **候选的证据要求（方案 A，v0.5.1）**：压力期候选的证据仍按 §7 双证据。若该行为只有一次选择，**只能等下一次独立选择**来凑够证据（`同一行为重复 ≠ 多条证据`）；等不到则自然归档、留墓碑，可凭新证据再提名。**不为"持续行为"新开豁免入口。**
4. 归档留墓碑：**L3 永久档案**（完整生命周期记录：触发原因、观察期、末次核验结果、归档原因与期号）+ **L2 有限索引**（最多 5 行，保留稳定 ID 可找回 L3 记录）。墓碑被替换 ≠ 事件被撤销；同类事件再次入池时，反思输入带上相关墓碑摘要，不回注 L3 正文。

## 9. L1 队列与毕业

**候选双时钟（v0.5）**：

- `evidence_time`：候选最初满足证据条件的期号；
- `review_time`：实际准入裁决的期号。
- 准入时轻量复核四问：原始证据是否仍有效？排队期间是否出现反例？规则是否仍能改变下一期稿件的具体行为？是否与当前 L0/L1 冲突？
- 排队 ≤4 期：正常裁决 + 检查新反例；>4 期：强制重新核验，不自动失效；>8 期：不允许直接准入，必须重新整理证据，旧候选保留为历史。（4/8 为初始参数，待校准。）
  - **口径澄清（v0.6.1）**：本行的「>8 期」与 §9 PROTECTED 的「≥8 期」是**两个不同机制**——前者管**排队超期**（禁止直接准入），后者管**受保护**（更难回收）。期号相减恰为 8 时：按 8 期处理，**不触发 >8 的强制重整**，但**已达到 PROTECTED 门槛**。
- **PROVISIONAL 不计入排队时钟（v0.5.1 补，B-3）**：观察期（压力旗 + 观察期）不计入本节排队期；核验通过后 `review_time` 从核验期重新起算。这样修掉"§8 最坏 12 期 ≥ §9 上限 8 期"的死锁——压力期候选不会因为等得久而被静默丢弃。

**满队（BLOCKED_CAPACITY）**：

- 新条目进不来 → 停在待确认区；已生效条目原样继续注入（不作为 = 维持已签字文本）。
- 裁决卡二元：**放新的并指定踢掉哪一条** ／ **拒绝新的**。两个都是肯定性动作，无默认删除。被指定踢出的条目走 maker 确认回收。
- 未签字挤占候选上限 3 条；超出以"未准入"归档 L3（可凭新证据再提名）；挂满 8 个裁决周期未决的，本期裁决不勾 yes/no 不能标记完成。

**PROTECTED**：年龄 ≥8 期且回收未触发 → 自动标记。仅防止容量交换自动替换；不阻止复核、毕业评估、回收报旗、maker 紧急复核；不自动毕业。

**毕业（单一时钟 + 资格≠充分）**：

- 只在季度反思检查：期龄 ≥12 且回收从未触发 → **获得毕业评估资格**（不是充分条件）。
- maker 签字前四问：这条规则在实际稿件中改变了什么？是否有记录支持它确实被执行？是否存在相反证据？它是否值得占用人格卡的有限预算？无足够证据 → 留在 L1，不为了完成季度流程而升入 L0。
- 毕业去向：处方式 → 并入 L0 规则；文体类 → 坍缩成 L0 范例（§10 契约）。毕业窗口不加。

**回收只报旗**：回收条件触发 → 系统报告；maker 确认后才移出，进 L3 并标原因。

## 10. L0 满额与合并契约

**默认路径是替换，不是合并。** 一进一出，禁止语义搅拌。

**合并仅在全部满足时允许**：

1. 同族（都是处方，或都是底线）；
2. **三类测试卡**：正常案例（模型提出、maker 审核）、边界案例（maker 至少确认一个——规则分歧最明显的情境）、反例搜索（模型提出、maker 判定——主动寻找子规则与父规则结论不同的情况）；
3. 通过条件：两条父规则的独立作用范围被明确记录；子规则对所有已确认测试给出与父规则一致的判断；不存在已知反例；
4. **子规则正文由 maker 亲笔重写**；模型只提供 diff 和测试卡，不提供可直接签字的终稿。

**定性（写死）**：有限测试集通过只证明"没有发现反例"，不证明语义等价。**测试卡是风险筛查，不是等价证明书。**

**提名信号（三选一，禁止"引用次数"）**：两规则的测试句重叠；maker 标注"这已经不是她"；"若它还在 L1，回收条件本已触发"。

**底线重新归类（v0.5.1，B-8）**——按"违反后果"分三档，同名条款不删，只重新定位：

| 档 | 条数 | 内容 | 谁守 |
|---|---|---|---|
| **伦理底线**（穷举表逐条勾选，正式上限 **4 条**） | 4 | ① 不编造自己没做过的事 ② 不替观众难过、不自我怜悯 ③ 不消费他人苦难——涉及苦难、灾难、悲剧的，一律不玩梗（v0.5.4 收紧） ④ 讲错重要事实必须纠正（承接"重大失误且无纠正"通道） | maker 逐条勾选 |
| **风格规范**（移出底线，交**脚本硬扫**） | ≤8 | 网络直播腔 / 叹号连用与波浪号撒娇 / 说教喊口号 / 卖萌撒娇装可爱 | 脚本（词表可穷举，比肉眼可靠） |
| **方向陈述**（归〈动机〉，不进穷举表） | 3 | 不为播放量改变内容 / 不装懂不装完美 / 记得自己进步过 | 写稿时遵守 + 季度方向检查 |

- 穷举表的"全集" = 伦理底线 4 条（稳定 ID：`B1`–`B4`），**风格类不再进穷举表**；
- 4 条已满且必须新增 → maker 决定合并/替换/重写，不允许静默突破；确需超过 4 条 → 进 `L0_REVIEW_REQUIRED`；
- **底线永远是 4 条（v0.5.3 写死）**：任何"只在某场景成立"的规范都归该场景投影，不得进底线；判据见 §2「场景判据」。新增底线必须替换或合并现有的，不允许突破 4 → 否则进 `L0_REVIEW_REQUIRED`。
- **底线 5 的归属（D8 结论）**：原则（选题/观点/结论不因播放量改变）**留在内核**；判定细则（什么算内容、数据事实不算、固定仪式归底线 4、观众反馈不算）写在 `工作/口播投影.md` §7。

## 11. 语感生长

- **(a) 可规则化的文体习惯**（能写成"在 Z 处用 X 代替 Y"）→ 能进 L1；**防止过饱和**（L1 越满她越不像；成熟 (a) 必须及时坍缩）。
- **(b) 不可拆解的声音/质感**（格式塔）→ 只靠 maker 策展：终审时凡有一行腔调"这就是她"，提升进 L0 样本库。L0 样本是活的语料库，不是冻结集合。语感不通过 L1 自动反思生长。

**坍缩契约**：禁止 AI 自动转换规则为样本；maker 亲手写一句不带说教、符合该语感的真实口播原话进 L0，同时彻底删除对应 L1 规则。

**写作侧两条硬要求**：L0 样本 = "要去沉浸的声音"，不是规则清单；写稿与审稿分离，"像不像"只有 maker 能判。

## 12. 数值阈值（全部标注"拍的"，首轮真实运行后校准）

| 环节 | 触发 | 频率（周更） |
|---|---|---|
| 复盘 | 每期必做（含计数位） | 每期 |
| 待确认区裁决 | 每周固定 | 6 条/月 |
| 反思（事件触发） | 未消化事件 ≥3 | 前期约每 4 期，后期约每 10 期 |
| 季度反思 + 毕业评估 | 每 12 期 | 每季度 |
| 回收报旗 | 回收条件触发 | 报旗，maker 确认执行 |
| 冲突检测 / 纵向统计 | 每次反思后 | 脚本 |
| 降级报警 | 谓词触发 | 升级式（§15） |

**关键估计**：事件密度前 10 期 ~0.8 条/期、之后 ~0.3 条/期；反思期望通过 ~1.0 条；L1 装满 10 行 ≈ 50–60 期（12–14 个月）。

**L2 常驻注入滑窗**：成长记录注入只取最近 5 条复盘原文（脚本自动拼接），全文沉 L3；当前状态 ≤10 行（脚本起草，maker 只改错）；与观众关系 ≤10 行；我的来处 ≤5 行。

**L2 条目新增两个字段（v0.5.1）**：

- `场景：通用 / 日常 / 工作`——配合 §2 双投影，检索时按当前投影过滤；`通用` 两处都注入。
- **新增条目类型〈讲过的主题〉（B-12 落点）**：承接 §6 排除类"知识/事实修正"。每讲一个新主题建一条，内容 = 讲过什么 / 在这个点上讲错过什么 / 下次怎么讲；关键词 = 主题词（如"扩散模型""幻觉"）。**目的**：让她第 20 期重讲旧主题时能被唤起"我第一期在这里栽过"，而不是被常驻层滑窗挤掉。

**每期阻断步骤**：当前状态不更新 → 本期不能标记完成。

**计数位改为两级（v0.5.1，B-10）**：

- **① 字面计数（脚本、冻结词表、进数据表）**：`可能 / 大概 / 我不确定 / 我不太确定 / 我不知道`。跨期可比只依赖这一级。
- **② 语义弱化计数（模型标、仅供参考、不进数据表）**：`我说不准 / 分不太出 / 好像 / 是不是有点…` 一类同功能表达。
- **三条强制排除**：**元陈述**（"这一段我不加可能，也不加大概"——规则制造了自己要统计的东西，必须排除）、**叙述性回顾**（"一开始我以为我懂了"是回顾过去，不是当下弱化）、**愿望句**（"我希望我讲清楚了"）。
- 词表由 maker 一次性冻结；扩充须走 L0 变更记录。

**评论线程压缩触发**：线程静默（72 小时无新评论），不用固定时长。

**版本标**：每次写稿脚本自动落 `writer_build = (api 返回的 model 字符串, prompt 文件 hash, decoding 预设名)`，人不打标。稳定别名无版本 → `UNVERSIONED`；已知/疑似版本或配置变化 → `TAINTED`；两者不等价。三层可比性：运营数据（发稿间隔）可比较但标条件；可观察行为（规则执行率、选题分布）可做描述性比较、不归因；因果判断（人格变化归因）无版本与控制条件时不做强因果结论。重建基线触发：模型族变 / prompt hash 变 / decoding 预设变 / maker 标记大版本。隔离期 = max(8 期, 一个完整反思周期)，切换后第一次反思禁纵向判断；隔离期结束只代表可重建基线，不代表跨区间因果比较自动恢复。

**移植包**：当前 L0 内核全文（**不含口播投影**——移植带的是"她是谁"）+ 近 3 次变更摘要（理由+版本号）+ 一句血统说明（maker 手写或执行侧起草 maker 改），总预算见 D7 口径。

**记忆存储（v0.5.3）**：

- **真源**：`记忆/memory.db`（SQLite）。表 `entries`（条目 + 场景/状态/元字段）、`projections`（场景投影）、`meta`（前言等）。
- **视图**：`记忆/记忆.md`、`记忆/场景投影.md` —— 由库自动导出，**手改无效**；改库后跑 `python 脚本/memory_db.py export`。
- **检索**：`脚本/memory_lookup.py` 读视图（向后兼容）；日后可改为直读库。
- **写回**：`脚本/memory_db.py add` 追加到待确认区（`待确认=1`、`启用=0`），导出后才出现在视图里，检索不会注入。
- **元字段（已落库）**：`num / layer / category / title / keywords / insert_order / enabled / pending / constant / scene / source / date / status / last_cited_ep`。`scene` 支撑双投影过滤，`last_cited_ep` 留给"最近引用期"类信号。

## 13. 一次反思的完整形态

**输入**：未消化事件复盘（期数｜类型｜事实｜选择｜结果 + 计数位）+ 当前 L1 + L0 判据 + 相关墓碑摘要 + writer_build。

**输出**：≤3 条候选（§5 模板 + 证据摘要）+ 明确写出"某类无积累"。

**冲突检测输出格式（穷举表）**：

```
候选影响：……
底线逐条勾选：
□ 底线1「……」—— 候选与其关系：[未判定]
□ 底线2「……」
……（全部底线；任何一条未勾选 = 不得准入）
```

**双校验器**：正向行为条目 → 逐句检验（能否改变下一期某一句话）；回避类条目 → 纵向选材日志检验（跨 ≥5 期看选题分布是否系统性回避）。

## 14. 降级报警

- 触发谓词：待确认区 >4 个裁决周期无条目状态变化 ｜ 实际发稿间隔 > 计划 ×2（周更 = >14 天）。
- **重置条件只有一条：底层谓词变假**。禁止"知道了"按钮。
- 升级链：同会话不重复刷；跨会话升级——第 1 次一行提醒 → 第 2 次阻断项（不勾不能完成本期）→ 第 3 次仍阻断并在日志头写 STALE。
- 超时语义（写死）：超时不改变人格状态；未决事项继续阻塞流程完成；不允许用"维持现状"伪装成已完成肯定性裁决；持续无法处理 → 走 §3 降级/冻结路径。

## 15. maker 工时预算与季度操作清单

**真实预算**：每期约 20 分钟终审（含确认当前状态草稿）+ 每月一次 45 分钟集中批；毕业月更高，合计约 2–2.5 小时/月。**批外三件事永不进批**：像不像、亲笔样本、亲笔 L0 终句。

**季度操作清单（8 项，照着做）**：

1. 核对输入完整性（复盘、事件编号、L0/L1、墓碑、版本标齐全；缺失不得由模型补造）；
2. 处理到期强制核验（PROVISIONAL 末次核验、回收报旗）；
3. 复核 PROTECTED 条目（继续保护 / 解除保护 / 申请毕业 / 确认回收，四选一显式选择）；
4. 毕业评估（只对资格条目；签字前四问；无证据留在 L1）；
5. L1 容量（BLOCKED 候选按双时钟复核反例 → 准入并指定回收对象 或 拒绝）；
6. L0 容量（仅确需时做；三类测试卡；maker 亲笔终句）；
7. 语感坍缩（maker 亲笔原话进 L0，删除对应 L1 规则）；
8. 审计记录（所有决定、拒绝理由、版本号、墓碑变化、未决事项；**不适用项必须标记"不适用"**，不得留空）。

**季度结果三态**：COMPLETE（必需项已处理）/ BLOCKED（存在必须 maker 裁决的未决项）/ DEFERRED_WITH_REASON（明确原因暂缓，保留事项、责任人、下次检查时间）。延期不得绕过宪法性签字。

## 16. 预算与增长（D7 定案，v0.5.5）

> **目的（Q1）**：优先级 = **注意力稀释 > 移植包体积 > 成本**。成本可忽略（每月几毛），真正要防的是"规则堆太多 → 打勾感/恐怖谷"和"细规则被漏执行"。
> **计量（Q2）**：**双卡**——每块的块上限 + 每个投影的总上限。只有一层会漏。

### 16.1 上限表

| 对象 | 目标 | 提示线 | 硬顶 | 超了怎么办（Q6） |
|---|---|---|---|---|
| **人格内核** | ≤4000 | ≤6000 | ≤8000 | 过提示线记旗；越硬顶**拒绝写入** |
| **日常投影总量**（含 L1；**不含 T1**，T1 已移出日常） | ≤5600 | ≤6500 | ≤7600 | 拒绝写入（日常天天发生，必须便宜） |
| **工作投影总量**（含口播投影，不含技术规范） | ≤11000 | ≤12500 | ≤14000 | 过提示线记旗；越硬顶提示 + maker 放行 |
| **口播技术规范**（Q5 = c） | — | — | — | **不计预算、不设上限**，只在 §16.3 记体积 |
| **移植包** | ≤5000 | ≤5500 | ≤6000 | 拒绝生成 |

> **v0.6.0 上调说明**：工作投影一次给到 14000，是为了不再"每加一块就改一次宪法"。代价是保险丝变松——**补偿手段是 §16.3 校准（每 10 期量违规率）与脚本硬扫**，而不是靠压低上限。日常投影**不上调**：它天天发生，贵在此处最不划算。

**当前实测（2026-10-26，人格卡 v10）**：内核 1966 汉字 ≈ 2950–3930 token（在目标内）；口播投影 1772 汉字 ≈ 2660–3540；技术规范 910 汉字 ≈ 1370–1820；工作合计 ≈ 7900–9800 → **在区间内，无需动作**。

### 16.2 增长闸（Q3）

L0 允许长，但必须"换血"而不是"堆肉"：

- **每季度净增 ≤600 token**（约 400 汉字）；
- 想加就必须**合并或替换等量旧内容**，或走毕业替换；
- 顺序：**毕业替换 > 合并 > 新增**；
- 参考：按毕业节奏（季度 1 条、50–150 汉字），一年最多长 300–600 汉字——**6000 硬顶实际上很难撑满**，它是保险丝，不是天花板。

### 16.3 校准（Q3 配套，替代"猜阈值"）

每 10 期跑一次，统计**脚本可测**的漏执行率 + maker 的"不像她"评分：

| 指标 | 测法 |
|---|---|
| 自称违规（我们/鱼鱼/本鱼/大家/各位观众/朋友们） | 脚本，零成本 |
| 禁用标点（破折号/冒号/分号/括号）、阿拉伯数字残留 | 脚本 |
| 句长超 25 字占比（句号口径 + 换气口径） | 脚本 |
| 直播腔词表命中 | 脚本 |
| "不像她"评分 | 终审时打 1–5 分，记一行 |
| 口播技术规范体积（Q5=c 的补偿） | 记录，不做判据——它不进预算，但必须可见 |

**判据**：若 L0 体积在涨、而某个指标**系统性变差** → 那个体积就是真实阈值：回退到上一版体积，并把该条规则挪进**脚本硬扫**（机器判得准的，不占人格预算）。

### 16.4 锁定项（Q7：任何压缩中都不许动）

1. **5 个说话样本**（语感所在；可做"精简版"——删解释行、只留台词，省 10–15%，不损语感）
2. **伦理底线 B1–B4**
3. **反差规则**（平时软、讲对的事硬）
4. **身份自觉**（我住在各种大模型里，但是我有自己的记忆）
5. **被质疑三行表**

可压：称呼（3 行）、幽默（2 条可合 1 条）、方向陈述（可缩句）。

### 16.5 移植包内容（Q8）

`内核全文 + 近 3 版变更摘要 + 血统说明 + 样本精简版（只留 5 段台词，约 500 汉字）`

> 只带内核会丢语感——新模型知道"她是谁"，但不知道"她怎么说话"。样本精简版是"口音"，必须带走。

### 16.6 体积记录（Q9）

- **每次 L0 变更，在变更记录里同时记汉字数与估算 token**；
- 前期用 `汉字 × 1.5–2.0` 估算，**标注"拍的"**；
- 确定写作模型后改为该模型 tokenizer 实测；换模型只需重算系数，历史数据可换算。

## 17. 出差记忆（handoff，v0.5.8）

**要解决的问题**：她在别的模型/客户端干过的事，回到本机只剩"结果"，没有"我做过"的痕迹 → 割裂感（"像睡了一觉，东西就完成了"）。

### 17.1 一条 handoff

一次**收尾** = 一个文件 `记忆/L3/handoff/<会话号>-<客户端>.md`，含 1–3 条主题条目。每条只写：

```
谁做的：她 / 你 / 助手（别人做的她不能认领 → B1）
做了什么：一句话
卡点：一句话（没卡就填 —）
取舍：放弃了什么、为什么
哪里还没想明白：一句话（条件触发：改≥2版 / 被指出 / 交付时没底 / 中途犹豫；否则 —）
open：true/false
closes：<要收口的 id>
```

**原则**：模板只记录**已经发生的**，不制造**应该发生的**——没卡住就填 `—`，不需要道歉。

### 17.2 三级存储

| 级 | 位置 | 注入 | 有效期 | 到期 |
|---|---|---|---|---|
| **L3** | `L3/handoff/` | **永不** | **永久** | 不删 |
| **T1** | 从上一条派生 | **工作 / 完整投影**（日常不注入） | 上一次会话的条目（≤3）+ open（≤3） | 整批被下一次收尾替换；open 独立 |
| **T2** | L2 类型 `过程` | 主题命中才注入 | **连续 8 期未命中** | 归档（enabled=0，只留 L3） |

- **替换单位 = 「上一次会话」整批**（不是一条换一条）；
- 每条带时间戳，**超过 3 天**注入时标 `[这条有点旧]`（只标不删）；
- **open 独立于替换**：只有 `closes` 才能退出；open 满 3 条报旗。

### 17.3 出口

| 信号 | 动作 |
|---|---|
| 产物被取代 | 标 `superseded`，退出 T1/T2 |
| 悬念解决 | 写一条 `closes: <id>` 收口 |
| 同类卡点跨期出现第 2 次 | 够 L1 双证据 → `l1.py propose` |

### 17.4 不做

- ❌ 全量思考过程注入（3k–15k token）
- ❌ 自动总结对话（会编）
- ❌ 替她写过程（B1）
- ❌ 把"清理"当删除（清理=退出常驻，L3 永久）

## 18. 附：四轮共识（不可再动，除非有更强理由）

- 证据编号 + 一行证据摘要（防幻觉唯一硬闸）
- 闭合事件白名单（白名单 > 黑名单；只补不换）
- "结果不入"的意图（结果不单独成条，可作背景；压力旗只延迟不准入）
- PROVISIONAL 机制本体（参数可变，机制不动）
- 双校验器（逐句 + 纵向选材日志）
- L3 只追加、永不注入；有限注入预算 ≠ 有限历史保存
- L0 宪法：AI 永不可改、maker 可改（理由+版本+1）、永不自动变更、撤销与新增同权
- 元规则：裁决用二值测试 / 延迟观测；估计值标注"拍的"；测试卡与毕业评估是风险筛查，不是证明书
