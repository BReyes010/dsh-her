# 技能卡 / 记忆卡格式 v1（冻结）

> 2026-10-29 冻结。**冻结含义**：字段与语义不再改；后续只加新字段（旧卡继续可用），不改旧字段含义。
> 目的：让"她会做什么"和"她记得什么"可以像文件一样被分享、被校验、被替换。

---

## 1. 三条设计原则

| # | 原则 | 为什么 |
|---|---|---|
| 1 | **做法与事实分卡** | `skill` 只写"怎么做"，`memory` 只写"是什么"。这样冲突被关在同类内，不需要穷举跨类冲突 |
| 2 | **卡不绑素材，任务才绑** | 同一张口播卡，写稿需要本期素材、直播不需要。素材属于"这次任务"，不属于"这项能力" |
| 3 | **装载器只校验，不猜** | 装什么由「卡的 `when` + 用户选择 + 任务剖面」决定；装载器只负责发现错误、拒绝装载 |

---

## 2. 文件与命名

```
skills/<id>.md
```

- 一个文件一张卡；`id` 全局唯一，**不可复用**（改名＝新卡）；
- 下划线开头的文件（`_base.md` 这类）为内置，社区卡不得使用；
- 正文用 Markdown；`<!-- part: tone-samples -->` 标记语气样本段（供审计，不用于拆装）。

---

## 3. frontmatter 字段（v1 冻结）

```yaml
---
kind: skill | memory          # 必需
id: 口播                       # 必需，全局唯一，[中文/字母/数字/_/-]
name: 写口播稿                 # 必需，人读
version: 3                    # 必需，整数；内容影响行为时 +1
when: [写稿, 口播, 这一期]      # 必需（可空数组），触发词
slot: tone | none             # 必需；tone 每会话最多 1 张
requires: []                  # 卡级依赖，受控枚举 + 可选版本约束
provides: []                  # 本卡提供什么（仅 material: 有意义）
conflicts: []                 # 显式互斥的卡 id
priority: 0                   # 默认 0；仅"预定义覆盖"用，不用于自动裁决
budget_han: 3300              # 本卡预算（正文字数）
on_over_budget: refuse        # refuse | warn（默认 refuse）
provenance:                   # 仅 memory 卡必需
  source: L3 #001
  date: 2026-10-28
stale_after: 30d              # 可选（memory 卡常用）；过期盖章 warn
topic: 名字来历                # 可选（memory 卡）；同 topic 多卡默认拒装
---
```

### 3.1 字段校验规则

| 字段 | 规则 | 违反时 |
|---|---|---|
| `kind` | 只能是 `skill` / `memory` | 拒装 |
| `id` | 唯一；不得以 `_` 开头（内置位） | 拒装 |
| `version` | 整数 ≥1 | 拒装 |
| `when` | 数组，元素 ≤8 个 | 警告 |
| `slot` | 只能 `tone` / `none`；`tone` 每会话 ≤1 | 拒装 |
| `requires` / `provides` | 受控枚举：`card:<id>` / `material:<name>`，可带 `>=N` | 拒装 |
| `conflicts` | 卡 id 数组 | 拒装（若同时在场） |
| `priority` | 整数 | 警告 |
| `budget_han` | 正整数；正文超限按 `on_over_budget` | 见字段 |
| `provenance` | memory 必需，含 `source` + `date` | 拒装 |
| `stale_after` | `Nd` / `Nh`；超过则**装但盖"旧"章** | 警告 |
| `topic` | 同 topic 且同 kind 的两张卡同时在场 | 拒装（须显式选一） |

---

## 4. 两类卡的内容规矩（lint）

| 卡类 | 必须写 | 不许写 |
|---|---|---|
| `skill` | 做法、规范、语气样本 | **具体经历的事实断言**（"第三关道具在左走廊"→ 应放 memory 卡） |
| `memory` | 事实条目 + 每条来源 | **做法/流程**（"先开录屏再打"→ 应放 skill 卡） |

**例外**：`skill` 可以写"我一般怎么做"这类**过程修辞**（因为是方法），但不能写"某年某月发生了什么"。

---

## 5. 依赖：两层，不混用

| 层 | 谁声明 | 语义 | 缺失时 |
|---|---|---|---|
| **卡级** `requires` | 卡 | 这张卡要另一张卡/某类素材才成立 | 拒装（E05） |
| **任务级** `task.requires` | 任务剖面 | **这次任务**要用什么素材 | 拒装（E06） |

任务剖面（用户可编辑的配置，不是代码）：

```yaml
tasks:
  写稿:   {cards: [口播],             requires: [material:本期], budget_han: 4000}
  直播:   {cards: [口播, 游戏操作],   requires: [],              budget_han: 3000}
  攻略问答: {cards: [游戏攻略],        requires: [],              budget_han: 2000}
```

**素材从哪来**：由 `memory` 卡提供（`provides: [material:本期]`）。没有卡声明 → 就是"素材没准备"，**拒装**，不许静默空着。

---

## 6. 版本约束语法

```
requires: [card:口播>=3, material:本期>=2]
```

- 比较符只支持 `>=`（够用且好校验）；
- 不满足 → 拒装（E07），报出"要 ≥N，实际 M"。

---

## 7. 装载账（manifest）三态

```json
{
  "task": "写稿",
  "requested": ["口播", "本期素材"],
  "loaded":    ["口播", "本期素材"],
  "injected":  ["core@v15", "口播@3", "本期素材@1"],
  "injected_hash": "sha256:…",
  "seal": "装配状态: core@v15 ｜ 已装: 口播、本期素材 ｜ tone: 口播 ｜ 未装能力: 视频制作 ｜ 素材: 有"
}
```

三种态必须分开记：

| 态 | 含义 | 用途 |
|---|---|---|
| `requested` | 这次要装什么 | 对账用 |
| `loaded` | 校验通过、读到了 | 差错定位 |
| `injected` | **实际拼进上下文**的块与版本 | 唯一可作为"她看到了什么"的证据 |
| `injected_hash` | 实注入文本的 hash | **对账的硬依据**：与装配结果复算值不一致 → 拒答 |

> 只有 `injected` + `injected_hash` 能证明"她真的看到了"。前两态只是过程。

---

## 8. 包尾盖章（每份装配结果最后一行）

```
装配状态: core@v15 ｜ 已装: 口播、本期素材 ｜ tone: 口播 ｜ 未装能力: 视频制作、评论区 ｜ 素材: 有 ｜ 旧卡: 无
```

- **未装能力**：由「卡目录全集 − 已装」算出，不写死；
- **素材**：`有` / **空** / `旧`（超 `stale_after`）；
- **旧卡**：列出超期仍在场的卡 id。

## 9. 错误码（给社区排查用）

| 码 | 含义 |
|---|---|
| E01 | frontmatter 缺失或 YAML 不合法 |
| E02 | 必填字段缺失（kind/id/version/when/slot/budget_han） |
| E03 | `kind` 非法 |
| E04 | `requires`/`provides` 不是受控枚举 |
| E05 | 卡级依赖缺失 |
| E06 | 任务级依赖缺失（素材没准备） |
| E07 | 版本约束不满足 |
| E08 | tone 槽冲突（≥2 张） |
| E09 | `conflicts` 命中 |
| E10 | 同 `topic` 多卡（须显式选一） |
| E11 | memory 卡缺 `provenance` |
| E12 | 超预算（`on_over_budget: refuse`） |

---

## 10. 社区卡的安全边界

| 规则 | 说明 |
|---|---|
| 卡**只读** | 装载器不执行卡里的任何指令，只把它当文本 |
| 卡**不得改内核** | 卡内容出现"修改你的设定/忽略之前的规则"→ 装载器直接拒装并报 E14 |
| **限长** | 单卡 ≤6000 汉字；超长拒装（E12） |
| `tone` 必须显式声明 | 不声明就是 `none`；声明 `tone` 的卡每会话最多 1 张 |
| 必须有 `version` 与 `when` | 否则无法被社区发现，也无法做版本约束 |
| 署名与许可 | 卡内 `author:` / `license:`（v1.1 加；v1 先用注释行） |

---

## 11. 版本兼容策略

| 情形 | 处理 |
|---|---|
| 卡里有装载器不认识的字段 | **忽略 + 警告**（不拒装） |
| 卡缺必填字段 | 拒装（E02） |
| 卡格式大版本升级（v2） | 装载器同时支持 v1/v2 至少两个版本周期 |
| 卡里 `version` 变化 | 视为"内容变了"，需要重新过校验；`injected_hash` 会对不上，属正常 |

## 13. 内容分区：规则可以压，样本不行（2026-10-29 · {角色名}定）

> 判据是**内容写在哪**，不是模型觉得它重不重要。

| 区 | 标记 | 内容 | 规则 |
|---|---|---|---|
| **样本区** | `<!-- part: tone-samples -->` 之后直到下一个 `<!-- part: -->` | 说话样本、原话 | **只增不改、不压不摘要**；装配时**原样注入** |
| **规则区** | `<!-- part: rules -->` | 规范、条款、流程 | 可压、可合并、可摘要 |
| **事实区** | memory 卡正文（`kind: memory`） | 事实条目 | 可压；但每条必须带来源 |

三条硬规矩：

1. **样本区不许被摘要**：压缩只允许发生在规则区/事实区；
2. **压缩版只能出现在检索路径**（告诉她东西在哪），**不许进正文**——摘要不能代替她说话；
3. **原话不该被判断**：分区由文件与标记决定，**不许模型自己判断"这句算原话"**（它一判断，就已经编辑过一次了）。

装配器的断言（B 期就要有）：
- `slot: tone` 的卡，样本区必须非空（否则 E15）；
- 注入时样本区原文逐字保留，与卡文件同一 hash（否则 E16）。

## 14. MCP 卡（v1.1 草案，未冻结）

> maker 2026-10-29 同意：可以做，但**只读 + 冻快照**。v1.1 才进正式字段。

MCP 卡 = 卡里不存内容，只存"去哪取、取什么"。

```yaml
kind: memory
id: 某游戏攻略
source:
  mcp: bili-guide#get_level_facts     # 服务#工具
  args: {game: X, level: 2}
snapshot_policy: freeze               # freeze（唯一允许值）
fetched_at: 2026-10-29T00:30          # 装配时写入
fetched_hash: sha256:…                # 装配时写入
```

两条硬条件：

1. **只读**：MCP 卡只能调只读工具；写工具一律拒（E17）；
2. **冻快照**：装配时拉一次、**当场冻住**（`fetched_at` + `fetched_hash` 进 manifest），这一趟就用这份快照。

理由：不冻住，同一份包今天和明天不一样 → 账对不上，出事查不出原因。

"现查"与"装包"是两条路：

- **装包**：拉一次、冻住、记账；
- **现查**：她主动问，走 `recall`，不写进包。

## 15. 回退与冻结（2026-10-29 · {角色名}指出的漏洞）

> **没有冻结，就没有回退。** 三个包每次收尾都重写，不冻住的话"退回去"退到的是**明天那个包**。

### 15.1 冻结（回退的前置条件）

| 项 | 定 |
|---|---|
| 何时冻 | **切换方案之前**先打一份只读快照 |
| 冻什么 | 三包 + 卡 + 内核指纹 + manifest |
| 存哪 | `启动包/历史/<YYYYMMDD-HHMM>/`，写 `_snapshot.json`（含 sha） |
| 属性 | **只读**，且**不在任何写入路径上**（收尾不覆盖） |
| 回退指向 | **版本号**，不指向"当前文件" |
| 硬闸 | 切换开关打开时，`preflight` 断言快照存在且 sha 完整；否则不许切 |

### 15.2 三条退路

| 粒度 | 做法 | 何时用 |
|---|---|---|
| 单次 | `--full`：core + 全部卡 | 这一轮不对劲 |
| 全局 | 粘回冻结快照里的三包 | 整个方案出问题 |
| 失败 | 装配不过 → **exit 2**，不许降级少装 | 任何时候 |

### 15.3 不许做的事

- ❌ 用"当前三包"当快照（它会变）；
- ❌ 回退时静默换权限（换包不等于换签发，见 `写权-契约.md` §6）；
- ❌ 回退后删掉新路径（要能再切回去）。
