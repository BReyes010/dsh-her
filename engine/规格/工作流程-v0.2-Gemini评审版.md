## 1. 背景与目标

- 「{角色名}」是 DeepSeek 的社区形象（网友画的蓝色肥鱼），现作为虚拟主播运营：口播稿由 AI 生成、TTS 朗读、发 B 站。
- 目标：她的人格和记忆要**"长"出来**——前期只有一句设定，之后每一期视频、每一次评论互动都成为她性格与记忆的来源。
- 长期愿景：人格与记忆以**纯文本、结构化、可溯源、自解释**的形式存盘，将来可整体移植给更强的模型。
- 两个硬约束：
  1. **L0（人格卡）只有 maker 能改**——AI 永不可改；maker 修改须附理由 + 版本号 +1，全程留痕；
  2. **一切自动沉淀必须经过人工裁决才能生效。**

## 2. 四层结构（v0.2）

| 层 | 内容 | 谁可写 | 注入方式 |
|---|---|---|---|
| L0 人格卡 | 她是谁、动机、禁止清单、玩梗判据、技术规范、说话样本 | **只有 maker**（理由+版本+1） | 每次写稿全文注入 |
| L1 自我认知 | "我最近变成了什么样"的行为规则，≤10 行 | 她提议 → maker 签字 | 每次写稿全文注入 |
| L2 经历（世界书） | 常驻层（当前状态 / 成长记录 / 与观众关系 / 我的来处）+ 关键词层 | 自动沉淀 → 待确认区 → maker 确认 | 常驻层注入滑窗；关键词层按主题命中 |
| L3 原始日志 | 每期成稿、复盘、历届 L1、全部事件、L0 变更历史 | 只追加 | **永不注入** |

**L1 的定位（v0.2 核心）**：L1 不是"会遗忘的滑窗"，而是 **"L0 修订案的暂存队列"**。它的每个条目都是一条候选 L0 规则，终点是毕业进 L0（或回收），而不是被挤出去。

**层间切分规则（写死，消除 L1/L2 边界模糊）**：

- **L1 = 处方式**：给下一期的行为规则（"做 X、避免 Y"）。能写成行为规则的，进 L1。
- **L2 = 叙事式**：发生过什么，供她当背景引用（"第 3 期讲错，第 5 期讲对"）。只能写成叙述的，进 L2。
- L2 常驻层里任何**处方内容**，一律清出来归 L1。

## 3. 核心机制：性格怎么"长"

**人格变化 = 往 L1 加一行（候选 L0 规则），而不是改 L0。** L0 只在 maker 签字 + 毕业机制下变化。

条目模板（v0.2 版，比 v0.1 多两个字段）：

```
#L1-NN｜日期｜标题
证据：#a、#b + 一行证据摘要（脱离 L3 仍可读懂、可核验）
影响：（具体到能改变下一期稿子的某一句话）
回收条件：（什么信号出现时收回这条）
```

实例：

```
#L1-01｜讲清的内容不再用道歉开头
证据：#2（第 2 期：观众"你为什么一直道歉"，自我怀疑句 4 次）、
     #3（第 3 期：第一次直接给结论，数据没涨但她不后悔）
影响：干货段落删掉开头的"可能是我搞错了"；"讲对的事硬"出现频率上升
回收条件：连续 3 期出现"讲得太硬被误解" → 收回
```

**检验标准**：一条 L1 条目的"影响"必须能改变下一期稿子里的某一句话；不能，就是废话（典型反例："我变得更加自信了"）。

**总原则（v0.2 精确版）**：性格由她的**选择**塑造；结果永不**单独**成为 L1 条目，但结果可以作为某个选择事件的**背景**。

- ❌ 数据差 → 她变了
- ✅ 数据差，但她决定继续做 → 她变了（失败只是背景）
- ⚠️ 边界情况：长期失败导致的"变谨慎"，按 §6 的 **PROVISIONAL 滞后期**处理

## 4. 事件类型闭合清单（v0.2）

**可以进 L1 候选的（5 类）**：

| 类型 | 判据 |
|---|---|
| ① 做对了"以前的她会做错"的事 | 与 L1 旧条目或 L0 样本对比可得 |
| ② 讲错被指，且改法涉及"怎么判断/怎么开口" | 纯知识错误不算 |
| ③ 被反驳且坚持住了 | "不争"的新边界具体化 |
| ④ 拒绝了一件事 | 选择定义性格 |
| ⑤ 学到改变做法的新东西 | 改的是"做法"，不是"知识" |

**排除的（5 类）**：知识/事实修正 → L2 主题索引；TTS 读法 → L2 技术表；数据涨跌本身 → 只进数据表；观众的一次夸奖或谩骂 → 外部结果；"她觉得自己变了" → 无行为证据的主观感受。

**关系变化不设事件类型**：关系进展走 L2 常驻层〈与观众关系〉的叙事更新通道（每期复盘顺手更新），**不进 L1**（L1 只收行为规则）。v0.1 反思输出里的"关系类"一行已删除。

**已识别的盲区（承认但暂不补类型）**：低于"事件"阈值的重复小选择（温水漂移）不会进入事件池，改由 §9 的季度纵向统计捕获。

## 5. 三道硬闸（v0.2）

1. **双证据**：一条 L1 条目默认需要 ≥2 条**不同期**的独立事件。
2. **无证据编号不写**：候选缺证据编号即拒绝（防幻觉的唯一硬机制，编号可核验）。
3. **结果不入，只认选择**（§3 精确版）。

**单证据豁免（v0.2 新判据，取代"类型④自动豁免"）**：

> 单证据豁免的充要条件 = **自明的昂贵选择**：在更安全 / 更省力 / 更默认的退路明显可得时，她选了代价更高的那条，且**代价内生于选择**（她主动放弃了什么），而非外生于舆论（外界反应多大）。

- 类型④（拒绝）满足：放弃了利益。
- 闯祸后当众认错纠正满足：放弃了面子。
- **"伤害多大"永远不是判据**——不含这个量，就没有"影响大不大"的刻度尺。
- **重大失误且无纠正**：不走 L1 自动通道，是 maker 直接修订 L0 的信号，不受证据数约束。

## 6. PROVISIONAL 滞后期（v0.2 新机制）

**适用**：诞生于持续外部压力期（数据差、争议期）的 L1 候选。

**流程**：

1. 反思提名时，若候选的触发背景是"持续外部压力"，标 `PROVISIONAL`，放在**待确认区**（不新建结构）。
2. 转正条件：**压力撤除后，行为依然留存**。
3. 核验时机：下一次反思或 maker 裁决时核验；**存疑就继续暂挂**，不轻易转正。

**原理**：把"这是结果塑造还是选择塑造"的当场哲学判断，推迟到可观测的时候——
结果塑造的变化是应激、可逆的，压力一反转它就反转，熬不过滞后期自己死掉；
选择塑造的变化熬得过滞后期，自然转正。**不需要任何主观刻度尺。**

## 7. L1 毕业机制（v0.2 核心新增）

**L1 条目生命周期**：候选（待确认区）→ 生效（L1）→ **毕业（L0）** 或 回收。

| 去向 | 条件 | 动作 |
|---|---|---|
| 毕业进 L0 | 回收条件连续 **5 期**（拍的，可调）未触发，行为稳定，maker 签字 | 处方式条目 → 并入 L0 规则（**替换同类，不纯追加**）；文体类条目 → **坍缩成 L0 范例** |
| 回收 | 回收条件触发，或与 L0 内核冲突 | 条目进 L3，标注回收原因 |
| 留在 L1 | 尚不满足毕业条件 | 继续占槽位 |

**坍缩成范例**：成熟的文体规则毕业时，不变成规则，而**合成一条新的 L0 说话样本**，用这条样本一次性示范所有规则。范例让模型"沉浸"，规则让模型"打勾"——**后者制造恐怖谷**（见 §8）。

**满队规则**：L1 满 10 行且新条目要进时，触发一次**强制毕业评审**，maker 三选一：毕业一条 / 回收一条 / 放弃新条目。**滑窗不再自动挤人**——挤出会让她"长回去"，挤出的唯一合法去向是毕业，不是遗忘。

**次生防护**：毕业进 L0 必须"替换同类"（合并同类样本/规则），防止修好 L1 的漏桶、撑破 L0 的桶。

## 8. 语感的生长（v0.2 新机制）

语感分两种，命运不同：

- **(a) 可规则化的文体习惯**（能写成"在 Z 处用 X 代替 Y"）→ 能进 L1，模板装得下。
- **(b) 不可拆解的声音 / 质感**（整体"像她"的格式塔，由上百个微选择涌现）→ **不住在任何规则里**，住在 L0 样本 + 写作模型的生成先验里。

**两条硬规则**：

1. **(b) 只靠 maker 策展生长**：每次终审，凡有一行腔调 maker 觉得"这就是她"，就把那一行提升进 L0 样本库。L0 样本是**活的语料库**，不是第一天冻结的集合。**语感不通过 L1 自动反思生长。**
2. **防止 (a) 过饱和**：L1 里文体微规则堆多了，写作模型会把"人格预算"花在逐条打勾上，产出的文字所有动作都对、合起来是恐怖谷。**L1 越满她越不像。** 因此成熟 (a) 规则必须及时坍缩成 L0 范例（§7），不在 L1 里长驻。

**给写作侧的两条 prompt 硬要求**（写死）：

- L0 样本的定位是"**要去沉浸的声音**"，不是"要遵守的规则清单"。同一批样本，当范例喂 → 保住格式塔；当规则清单喂 → 制造恐怖谷。
- 写稿与审稿分离：模型写、模型只做技术修正，**"像不像"只有 maker 能判**。

## 9. 数值阈值（v0.2 修订版）

**前提判断不变：上下文长度不是触发器。** 写稿是子代理冷启动，上下文不累积；触发器绑在事件数、条目数、L1 行数上。

| 环节 | 触发条件 | 频率（周更节奏） | 单次成本 |
|---|---|---|---|
| 复盘 | 每期必做 | 每期 | 1 行 |
| 待确认区裁决 | 每周固定 | 6 条/月 | maker 约 10 分钟/月 |
| 反思（事件触发） | 未消化事件 ≥ 3 | 前期约每 4 期，后期约每 10 期 | 输入 2–3k token |
| 反思（时间兜底） | 连续 12 期未触发 | **每季度**（12 期周更 ≈ 3 个月） | 同上 |
| L1 毕业评审 | 条目满 5 期或 L1 满队 | 随反思 | maker 签字 |
| 冲突检测 | 每次反思后 | 同上 | 脚本 |
| 降级报警 | 待确认区 >2 周期未动 / 当前状态 >2 期未推进 | 触发时 | 零成本，弹窗提醒 |

**v0.2 修正后的关键估计**（全部标注"拍的"，仅作容量预估，不作裁决依据）：

- 事件密度：前 10 期 ~0.8 条/期，之后 ~0.3 条/期。
- 反思期望通过：**~1.0 条/次**（v0.1 写 1.5，被评审指出与双证据不自洽）。
- L1 装满 10 行：**约 1.5–2 年**（v0.1 写"半年"，评审指出我把早期密度一路算到底；按 0.3 后期密度重算后为 55–90 期）。
- 兜底 12 期 = **季度**（v0.1 写"每年一次"，与"周更节奏"表头矛盾，已修正）。

**L2 常驻层注入滑窗（v0.2 新）**：

- 成长记录：注入只取**最近 5 条 + 一句阶段性总结**，全文沉 L3（"只追加"原则保留——追加是证据链，滑窗只管注入）。
- 当前状态 ≤10 行；与观众关系 ≤10 行；我的来处 ≤5 行。

**评论连续事件源（v0.2 新）**：评论事件**汇入下一期的事件池**（不按视频期单独开通道）；活跃线程的压缩触发 = **线程静默（72 小时无新评论，拍的）**，不用固定时长——固定 48h 会中途压缩掉活跃上下文。

**每期流程的阻断步骤（v0.2 新）**：

- 「当前状态」不更新，本期不能标记完成（把静默失忆从"希望"变成"阻断"）。
- 复盘必须带计数位：本期"可能/大概/我不确定"出现次数（为季度纵向统计供数）。

## 10. 一次反思的完整形态（v0.2）

**输入**：未消化事件复盘（每行含：期数｜事件类型｜一句话事实｜她的选择｜结果 + 计数位）+ 当前 L1 + L0 判据。

**输出**：≤3 条候选（按 §3 模板，含证据摘要）+ 明确写出"某类无积累"。评审样例：

```
✅ #L1-01｜讲清的内容不再用道歉开头（见 §3 实例）
✅ #L1-02｜拒绝过的热点，以后连看都不看
   证据：#3（第 3 期：拒绝了苦难类热点，数据比上期低，她决定继续）
   影响：选材跳过"笑点建立在别人疼上"的题；稿子里不提"我拒绝了它"
   回收条件：她开始把"拒绝"当人设卖点 → 收回
❌ "数字先转中文再念" → 技术修正，转走 L2 技术表
❌ "我变得更加自信了" → 形容词、无证据、无法改变下一期任何一句话
（"关系类"不再出现在反思输出——关系走 L2 常驻叙事通道）
```

**冲突检测（v0.2 定义落地）**：

- 检测范围：L1×L0、L1×L1（新旧互斥 → 回收旧的）、候选×L0。
- 裁决规则：**每条 L1 必须能被解释为 L0 内核（追求成长、消化快、继续做）的一个具体化**，否则拒绝。
- 裁决人：maker。反思模型只提名，提名时附一行"它如何是 L0 内核的具体化"。
- 撞了以后：L0 胜，L1 条目回收，不静默。

**双校验器（v0.2 新）**：

- 正向行为条目 → **逐句检验**（能否改变下一期某一句话）。
- 回避类条目（"不提/不做 X"）→ **纵向选材日志检验**（跨 ≥5 期看选题分布是否系统性回避）。单期稿子里"不出现"不可观测，只能纵向看。

## 11. 请评审者（Gemini）重点挑刺的 12 个问题

1. **毕业通道的反噬**：L1 → L0 毕业 + maker 直改 L0，两条通道都会让 L0 持续膨胀。"替换同类、不纯追加"能挡住多少？L0 样本区十年后多大才合理，要不要给 L0 也设上限？
2. **毕业条件"连续 5 期未触发回收"是拍的**。5 期会不会太短（一条规则只稳定了 5 周就进 L0，凭什么算"成熟"）？
3. **满队强制三选一**（毕业/回收/放弃）会不会变成 maker 的新负担——闸太多，maker 从"每月 10 分钟"变成批文机器？整套系统现在 maker 每月的总工时是多少？
4. **"坍缩成范例"的具体机制未定义**：一条 L0 样本怎么"示范"多条规则？范例由谁起草（模型起草 maker 改，还是 maker 手写）？会不会范例越写越长、越写越像说明书，反而丢失了"沉浸"效果？
5. **"自明的昂贵选择"由模型提名 + maker 拍板**：提名阶段模型会不会把普通选择包装成"昂贵选择"？要不要强制提名必须附"退路对比行"（她当时还可以怎么做）？
6. **PROVISIONAL 滞后期缺参数**："压力解除"怎么定义（数据回升？争议平息？连续几期）？滞后期没有上限会不会永远暂挂、把待确认区塞满？
7. **"可解释为 L0 内核的具体化"仍然偏软**——它自己是个主观判断，和"裁决用二值测试"的元规则是否矛盾？有没有办法二值化？
8. **季度纵向统计（温水漂移）缺基线**：第一年没有历史基线，统计出来的"漂移"和什么比？自我怀疑句的计数口径会不会被写作模型漂移污染（换了写作模型，计数全变）？
9. **评论汇入事件池**：一条评论要凑成"选择事件"，比视频事件难得多（没有"昂贵代价"）。会不会评论事件 99% 沉进事件池后永不触发反思，等于白收？
10. **L2 常驻滑窗的"一句阶段性总结"由谁维护？** 它会不会变成第二个"当前状态"，又新增一个需要人工更新的点，最后和"当前状态"互相打架？
11. **降级报警的阈值"2 个周期"**：拍的吗？maker 休假两周就被报警，会不会狼来了？
12. **L0 修订通道的版本历史放哪**：放 L3（永不注入）合理吗？新模型移植时只拿到"当前版本 L0"，历史版本要不要一起带走？带走的话，"可溯源"和"注入精简"怎么平衡？
