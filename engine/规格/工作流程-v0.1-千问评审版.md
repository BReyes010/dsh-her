# {角色名}人格生长系统 · 工作流程（评审版 v0.1）

> **用途**：整份交给第三方模型（千问）挑刺用。全文自包含，不依赖任何本地文件。
> **评审请求**：请以"找漏洞"为目标逐节审阅，重点回答第 10 节的 12 个问题。输出不需要客气，越具体越好；对每个阈值和规则，请直接说"这个数/这条规则我不认可，理由是……"。

---

## 1. 背景与目标

- 「{角色名}」是 DeepSeek 的社区形象（网友画的蓝色肥鱼），现作为虚拟主播运营：口播稿由 AI 生成、TTS 朗读、发 B 站。
- 目标：她的人格和记忆要**"长"出来**——前期只有一句设定，之后每一期视频、每一次评论互动都成为她性格与记忆的来源。
- 长期愿景：人格与记忆以**纯文本、结构化、可溯源**的形式存盘，将来可整体移植给更强的模型（"她"不被任何一家厂商绑定）。
- 两个硬约束：
  1. **人格卡只有 maker（她的制作者）能改**，任何 AI 不能；
  2. **一切自动沉淀必须经过人工裁决才能生效。**

## 2. 四层结构

| 层 | 内容 | 谁可写 | 注入方式 |
|---|---|---|---|
| L0 人格卡 | 她是谁、动机、禁止清单、玩梗判据、技术规范、说话样本 | 只有 maker | 每次写稿全文注入 |
| L1 自我认知 | "我最近变成了什么样"的行为倾向，≤10 行滑窗 | 她提议 → maker 签字 | 每次写稿全文注入 |
| L2 经历（世界书） | 常驻层（当前状态 / 成长记录 / 与观众关系 / 我的来处）+ 关键词层（梗、人物、技术实测、讲过的主题） | 自动沉淀 → 待确认区 → maker 确认 | 常驻层每次注入；关键词层按主题命中注入 |
| L3 原始日志 | 每期成稿、每行复盘、历届 L1、全部事件 | 只追加 | **永不注入** |

分层理由：性格是常量（L0），经历是变量（L2），**自我认知是两者之间的缓冲（L1）**——她可以变，但变的是 L1，不是 L0。

## 3. 核心机制：性格怎么"长"

**人格变化 = 往 L1 加一行，而不是改 L0。**

条目模板：

```
#L1-NN｜日期｜标题
证据：#a、#b        （事件编号，必须可回溯）
影响：（具体到能改变下一期稿子的某一句话）
回收条件：（什么信号出现时收回这条）
```

实例：

```
#L1-01｜讲清的内容不再用道歉开头
证据：#2、#3
影响：干货段落删掉开头的"可能是我搞错了"；"讲对的事硬"出现频率上升
回收条件：连续 3 期出现"讲得太硬被误解" → 收回
```

**检验标准**：一条 L1 条目的"影响"必须能改变下一期稿子里的某一句话；不能，就是废话（典型反例："我变得更加自信了"）。

**总原则：性格由她的"选择"塑造，不由外部"结果"塑造。**

- ❌ 数据差 → 她变了
- ✅ 数据差，但她决定继续做 → 她变了

## 4. 事件类型闭合清单

**可以进 L1 候选的（5 类）**：

| 类型 | 判据 |
|---|---|
| ① 做对了"以前的她会做错"的事 | 与 L1 旧条目或 L0 样本对比可得 |
| ② 讲错被指，且改法涉及"怎么判断/怎么开口" | 纯知识错误不算 |
| ③ 被反驳且坚持住了 | "不争"的新边界具体化 |
| ④ 拒绝了一件事 | 选择定义性格 |
| ⑤ 学到改变做法的新东西 | 改的是"做法"，不是"知识" |

**排除的（5 类）**：知识/事实修正 → L2 主题索引；TTS 读法 → L2 技术表；数据涨跌本身 → 只进数据表；观众的一次夸奖或谩骂 → 外部结果；"她觉得自己变了" → 无行为证据的主观感受。

## 5. 三道硬闸

1. **双证据**：一条 L1 条目默认需要 ≥2 条**不同期**的独立事件；唯一例外是类型④（拒绝），可单证据（代价本身可见）。
2. **无证据编号不写**：候选缺证据编号即拒绝——这是防幻觉的唯一硬机制，因为编号能被核验。
3. **结果不入，只认选择**（见第 3 节总原则）。

## 6. 数值阈值

**前提判断：上下文长度不是触发器。** 写稿采用"子代理冷启动"：每次重新注入，会话之间不共享上下文，上下文长度永不累积。会累积的只有事件数、条目数、L1 行数——触发器绑在这三者上。

| 环节 | 触发条件 | 频率（周更节奏） | 单次成本 |
|---|---|---|---|
| 复盘 | 每期必做 | 每期 | 1 行 |
| 待确认区裁决 | 每周固定 | 6 条/月 | maker 约 10 分钟/月 |
| 反思（事件触发） | 未消化事件 ≥ 3 | 前期约每 4 期，后期约每 10 期 | 输入 2–3k token |
| 反思（时间兜底） | 连续 12 期未触发 | 每年一次 | 同上 |
| L1 滑窗挤出 | 反思通过后自动 | 约半年装满，此后每反思挤 1–2 条旧条目进 L3 | 自动 |
| 冲突检测 | 每次反思后 | 同上 | 脚本 |

**估计依据**（欢迎打这些数）：事件密度前 10 期 ~0.8 条/期（早期犯错多、选择多），之后 ~0.3 条/期；每次反思平均通过 ~1.5 条；故 L1 约 7 次反思（≈26 期 ≈ 半年）装满 10 行。

**备用阈值（将来）**：若出现长程对话场景（评论区/私信多轮），单线程 ≥ 20k token 或 ≥ 48 小时 → 压缩成一条事件摘要进 L2。当前用不上。

## 7. 一次反思的完整形态

**输入**：未消化事件复盘（每行含：期数｜事件类型｜一句话事实｜她的选择｜结果，另附一个计数位——本期"可能/大概/我不确定"出现次数）+ 当前 L1 + L0 判据。

**输出**：≤3 条候选（按第 3 节模板）+ 明确写出"某类无积累"。评审样例：

```
✅ #L1-01｜讲清的内容不再用道歉开头（见第 3 节实例）
✅ #L1-02｜拒绝过的热点，以后连看都不看
   证据：#3
   影响：选材跳过"笑点建立在别人疼上"的题；稿子里不提"我拒绝了它"
   回收条件：她开始把"拒绝"当人设卖点 → 收回
❌ "数字先转中文再念" → 技术修正，转走 L2 技术表
❌ "我变得更加自信了" → 形容词、无证据、无法改变下一期任何一句话
⭕ 关系类：本期无积累
```

## 8. 已识别的失败模式与对策

| # | 失败模式 | 对策 |
|---|---|---|
| 1 | 表演成长（被要求"总结变化"就必然产出变化） | 允许并默认输出"无变化"；无证据编号不写 |
| 2 | 性格被结果带跑（数据差→变丧，数据好→变开朗） | 结果不入，只认选择 |
| 3 | 形容词化（"更自信""更勇敢"） | 检验标准：能否改变下一期某一句话 |
| 4 | 静默失忆（「当前状态」漏更新 → 永远停在旧时间点，且不报错） | 时间兜底反思 + 每期复盘时核对 |
| 5 | "不提"类影响不可验证（不出现 ≠ 生效） | 选材记录：每期记候选主题、她跳过了哪个 |
| 6 | 数据回填与反思职责重叠（两处都写"她怎么看待"） | 数据表只记数字+一句事实；看法只由反思产生 |
| 7 | 待确认区堆积 → 裁决形同虚设 | 人的带宽预算 6 条/月；超出即放慢 |
| 8 | 讲过的主题无索引（第 10 期重讲第 1 期讲错的概念却不自知） | L2 增加"讲过的主题"索引 |

## 9. 工作日历

- **每期**：写稿（写作强模型出稿 → 技术修正 → maker 终审"像不像"）→ 复盘 1 行 → 沉淀待确认区 → 更新常驻层「当前状态」→ 数据回填
- **每月**：待确认区裁决一次（通过 / 修改 / 丢弃，约 10 分钟）
- **每 4–10 期**：反思一次（克制模型 + 硬模板出候选 → maker 签字 → L1 更新 → 冲突检测 → 旧条目进 L3）
- **每 12 期**：强制反思一次（抓趋势）

## 10. 请评审者重点挑刺的 12 个问题

1. "未消化事件 ≥ 3"这个阈值有没有根据？事件密度 0.8 → 0.3 的估计是否站得住？
2. 双证据规则会不会挡住"一次决定性事件"（比如一次重大翻车）？该不该有"单事件但影响大"的例外？怎么判定"影响大"？
3. 时间兜底 12 期是否太晚或太早？
4. L1 上限 10 行是拍脑袋吗？它和"像不像"之间是什么关系？
5. 反思环节故意不用"写作强"的模型、改用克制模型+硬模板——是否会把"性格里偏语感的部分"（措辞习惯、节奏感）挡在 L1 之外？那一部分如果长不出来，怎么办？
6. 五类事件清单闭合吗？有没有会改变人的性格、却不在清单里的类型？
7. "结果不入、只认选择"——长期持续失败导致人真的变谨慎，这算结果塑造还是选择塑造？边界怎么划？
8. 检验标准"能否改变下一期某一句话"对"不提类"影响失效（第 8 节 #5），检验标准本身是否需要第二套？
9. 人工裁决会不会让 maker 成为整个系统的吞吐瓶颈？6 条/月的预算太乐观还是太悲观？
10. 冷启动架构下"上下文不是触发器"这个前提，将来引入长对话后还成立吗？20k token / 48h 的备用阈值合理吗？
11. L0 永不可改是不是太绝对？十年后她的"性格内核"真的不需要 maker 修订吗？
12. 四层结构里有没有冗余（比如 L1 和 L2 常驻层的边界）？哪一层可以被合并或删除？
