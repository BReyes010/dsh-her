# 流程：改人格卡（L0）

> 这份是**操作手册**，不是规范。规范在 `四层规范合集.md`；这里只写"谁、按什么顺序、敲什么命令"。
> 最后更新：2026-10-27（v13 落地 + 物理上锁之后）

---

## 0. 三条铁律

| # | 铁律 | 靠什么保证 |
|---|---|---|
| 1 | **只有 maker 能改 L0** | 文件 ACL：`Users: 只读`，只有 `Administrators` 可写 |
| 2 | **agent 只能写提案** | 约定文件 `人格/人格卡.proposed.md`，`l0_apply.py` 才落盘 |
| 3 | **每次改动留痕** | `l0_apply.py` 自动写 `记忆/L3/L0-changelog.md`（版本/理由/汉字数/token）+ 备份 |

**物理 + 流程两层都要**：ACL 挡"顺手改"，指纹挡"提权后忘了记"。

## 2. 标准五步

### 第 1 步：起草提案（我做，或你手写）

**位置固定**：`人格与记忆/人格/人格卡.proposed.md`（这个目录**不在锁内**，所以我能写）

- 提案是**完整文件**（不是 diff），从现役卡复制改；
- 标题版本号必须 **+1**（`v13` → `v14`），否则 `l0_apply.py` 拒收；
- 变更理由**先想好一句话**（会写进 changelog）。

### 第 2 步：看差异

```powershell
# 在任意窗口（读不需要提权）
cd "{PROJECT_ROOT}\{角色名}{项目名}\人格与记忆"
python 脚本\l0_apply.py --status
Compare-Object (Get-Content 人格\人格卡.md) (Get-Content 人格\人格卡.proposed.md)
```

`--status` 会打印：现役版本 + 汉字数、提案版本 + 汉字数。

### 第 3 步：提权落盘

```powershell
# 必须管理员窗口（UAC 点"是"，标题带"管理员"）
cd "{PROJECT_ROOT}\{角色名}{项目名}\人格与记忆"
python 脚本\l0_apply.py --accept --reason "改了什么、为什么"
```

它会做五件事：

```
✓ v13 → v14（汉字数，约 X–Y token）
✓ 备份 → 备份\L0\人格卡.v13.bak-<时间>.md
✓ changelog 追加一行
✓ 更新指纹（cards/_registry.json）
✓ 删除提案文件
```

**失败会明确报错**，不会留半套状态。

### 第 4 步：验证

```powershell
# 普通窗口即可
python 脚本\l0_guard.py
```

期望：

```
✓ L0 守卫：OK
  版本：正本 v14 ／ 登记 v14
  指纹：正本 xxxxxxxx ／ 登记 xxxxxxxx
  ✓ 物理保护生效：当前用户对「人格」目录只读（改卡须提权）
```

### 第 5 步：同步下游（容易忘）

改完卡必须同步这三处，否则"她说的"和"卡里写的"会分叉：

```powershell
# 1) 模板卡（开源用，带"模板说明"横幅）
python - <<'PY'
# 见 脚本/sync_template.py（如未建，用 l0_apply 的配套步骤手工同步）
PY

# 2) 启动包（她要用的那份文本）
python 脚本\make_pack.py

# 3) 检查预算（卡变大了没）
python 脚本\budget.py
```

## 3. 出问题怎么办

### A. guard 报「未登记的变更」

原因：有人（或某个 agent）直接改了卡，没走提案。

```powershell
python 脚本\l0_guard.py        # 看是哪个版本对不上
```

处理：

- **追认**：把改动留成提案（复制现役卡 → 改版本号 +1 → 写提案）→ 走第 3 步 accept；
- **回滚**：从 `备份\L0\` 取上一版覆盖 → 提权窗口里 `Copy-Item` → 再跑 `l0_guard` 对齐指纹。

### B. 卡变得"读不了"（ACL 被清空）

症状：`Get-Content` 报"访问被拒绝"；`icacls` 只显示 `Mandatory Label`，没有访问规则。
原因：`icacls /reset` 遇上了"受保护 + 空 DACL"的文件。

**修复（按顺序试）**：

```powershell
# 1) 常规修复
Start-Process powershell -Verb RunAs -ArgumentList '-NoExit','-Command','cd "{PROJECT_ROOT}\{角色名}{项目名}\人格与记忆"; powershell -ExecutionPolicy Bypass -File .\脚本\fix_l0_acl.ps1 -Writable'

# 2) 还不行 → 逐文件重建（必须用这个，/T 修不了空 DACL）
Start-Process powershell -Verb RunAs -ArgumentList '-NoExit','-Command','cd "{PROJECT_ROOT}\{角色名}{项目名}\人格与记忆"; powershell -ExecutionPolicy Bypass -File .\脚本\fix_l0_acl2.ps1 -Writable'
```

### C. 想临时解锁改点东西

```powershell
# 解锁（恢复成大家可写）
.\脚本\fix_l0_acl2.ps1 -Writable
# ……改完……
# 重新上锁
.\脚本\protect_l0.ps1
```

### D. 想彻底撤销保护

```powershell
.\脚本\protect_l0.ps1 -Revert
```

## 4. 三个已踩过的坑（别再踩）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **PowerShell 5.1 读 UTF-8 无 BOM** | 脚本报"缺少右 }"、中文变乱码 | `.ps1` 一律存成 **UTF-8 with BOM**；或消息用英文 |
| **`icacls` 用中文组名** | `BUILTIN\Users` 解析失败、半套权限 | 一律用 **SID 语法**：`*S-1-5-32-545:(OI)(CI)RX` |
| **`.NET` 规则用字符串 SID** | `IdentityNotMappedException` | 用 `New-Object SecurityIdentifier('S-1-5-32-545')` **对象** |

## 5. changelog 的记录格式

`记忆/L3/L0-changelog.md` 每行一条：

| 版本 | 日期 | 理由 | 汉字 | 估算 token |
|---|---|---|---|---|
| 人格卡 v13 | 2026-10-27 | 把变更说明与配套指针移出卡 | 1668 | 2502–3336 |

**理由要写"为什么"，不写"改了什么"**——改了什么看 diff 就知道，为什么只有你知道。
