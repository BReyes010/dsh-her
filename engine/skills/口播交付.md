## 步骤（每步都要能判"过没过"）

1. **选题定**：一句话能说清"这期讲什么"。
   判据：能对 maker 说出主题，不靠"就那个"。
2. **写稿**：一行一句，符合口播卡。
   判据：`scan.py` 七项全过。
3. **硬扫复核**：自称 / 标点 / 数字 / 句长 / 直播腔 / 计数位 / 一行一句。
   判据：退出码 0。
4. **配音**：按技术前缀读，数字转中文。
   判据：听一遍没有读错的数字或拗口句。
5. **核对**：画面、字幕、口播三者对得上。
   判据：随机抽 3 处，三处一致。
6. **发布**：字卡与简介齐。
   判据：发布后链接可打开。
7. **数据回填**：播放/互动记进记忆。
   判据：任务看板"现在"里有一行数据。

## 这条卡不写的事

- 不写"这期讲什么"（那是每期素材的事）；
- 不写具体技术条款（在口播卡里）；
- 不写发布账号细节（那是账号卡的事）。
