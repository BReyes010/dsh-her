## 一句话

这张卡是**给维护者看的**，不是角色的一部分。答"引擎怎么修、坏了怎么办、升级怎么做"。

## 先跑诊断，别先猜

| 想知道 | 跑什么 |
|---|---|
| 哪儿坏了 | `python 脚本/her-doctor.py`（九段，只读，给人话建议） |
| 我在本机改坏了没 | `python 脚本/selftest.py`（27 项，沙箱副本） |
| 端到端还通吗 | `python 脚本/healthcheck.py`（40 项，含 MCP 与真实引擎指纹） |
| 开场会不会炸 | `python 脚本/preflight.py --mode 日常` |
| 包和记忆同版吗 | `python 脚本/budget.py`、`pack_assembler.py check --task …` |

## 目录地图（三句话）

1. **代码**：`脚本/`（CLI）与 `入口/`（`her-host.py` 给她用、MCP 服务、提案入口）。
2. **数据**：`人格/`（L0 卡 + L1 规范，只读）、`记忆/`（L2 库 + L3 日志）、`入口/任务看板.json`、`skills/`（卡）。
3. **生成物**：`启动包/`（三包 + 装配版 + 历史快照）、`发布/stage/`（发布树）。

## 四条铁律

1. **不直接改 `人格/`**：走 `spec_apply.py propose` → 管理员签字 → 自动备份 → 自动 preflight。
2. **不在真数据上做破坏性测试**：`selftest` / `healthcheck` 自带副本；手写测试也要复制到 `.tmp-*`。
3. **改之前先冻快照**：`snapshot.py freeze --note "…"`；没有快照就不许动结构。
4. **交付给路径**：不要只说"改好了"。

## 常见故障 → 处置

| 症状 | 先看 | 常见原因 |
|---|---|---|
| 没有这张卡 | `cards/_registry.json` 与 `card.json` 的 id 是否一致 | 初始化没跑 / 注册表是空的 |
| 取包失败 | 直接跑 `入口/her-host.py --print 日常` 的真实报错 | 路径写死、文件被改名 |
| 写不进去 | `grant.py list` | 没签发 / 票用光 / 24h 额度满 |
| 收尾有子步骤失败 | 看它点名哪一步 | 索引建失败、归档 sha 不符、三包刷新失败 |
| 手改过任务看板 | `workbench.py import-md` 合并，或 `--force` | `md_sha` 对不上 |
| 忘了改了什么 | `记忆/L3/_任务看板.jsonl`、`_签发.jsonl`、`_提案.jsonl` | 审计链 |

## 改代码之后必须做

```
python 脚本/selftest.py      # 27 项
python 脚本/healthcheck.py   # 40 项
python 脚本/her-doctor.py    # 全绿
```

三条全绿才算改完；有一条红，先修红，不许"下次再说"。

## 发布（v1）

```
python 脚本/release_stage.py         # 生成 发布/stage/<日期>
python 脚本/release_check.py --dir 发布/stage/<日期>   # 私有串必须 0
```

然后在**空目录**里解包 → `her_home.py init --dest .` → `her-doctor.py` 全绿才算能发。

## 不可逆动作清单（做之前先问人）

| 动作 | 为什么 |
|---|---|
| `snapshot.py restore` | 覆盖现役文件 |
| `memory_db.py import --force` | 重写 L2 |
| `card.py retire --as retired` | 卡消失（可恢复） |
| 改 `_归档.json` / `baseline` | 历史账本 |
| 任何 `--force` | 都是绕过防护 |
