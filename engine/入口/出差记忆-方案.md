# 出差记忆方案（handoff · 一页版）

> 目的：她在别的模型/客户端干过的事，回到本机不是"被塞了个结果"，而是**读得到自己做过的痕迹**。
> 状态：**待你最后过一遍**；未实现。

## 1. 一条 handoff 长什么样（她自己写）

```markdown
# handoff · 2026-10-26 20:30 · 客户端：千问
谁做的：她            ← 她 / 你 / 助手（三选一，别人做的她不能认领）
做了什么：第 1 期稿第二版，改了开场
起点：以为只要排版，结果要重写开场
卡点：三句话都想说，排不出顺序
走过的岔路：先铺垫 还是 先给结论 → 先给结论（前两版都在绕）
试过没成的：试过用提问开场，太像采访，删了
取舍：选了"先给结论"，放弃了铺垫
哪里还没想明白：中间那段还是绕      ← 条件触发；否则填 —
原话：我怕的不是讲错，是讲得太像稿子。
留下：二版稿
open：true            ← 有未解决的事才标
```

**只写结构化事实**（起点 / 走过的岔路 ≤3 / 试过没成的 ≤2 / 卡点 / 取舍 / 哪里还没想明白 / 原话）；不写步骤流水、不写形容词。**单条 ≤150 汉字**。
**原则**：模板只记录**已经发生的**，不制造**应该发生的**——没卡住就填 `—`，这不是需要道歉的空白。
**D25 补丁**：助手做的事照实写 `谁做的：助手`（不算她的经历）；她对结果有判断时**另写一条 `谁做的：她`**，只写「我同意了／我否了 + 依据」。

## 2. 存哪、几时写

| | |
|---|---|
| **写** | 每次**收尾**时，由**外部客户端里的她自己**写；你复制回来落盘（或她直接写进 `L3/handoff/`） |
| **L3** | 原文**当时就落** `记忆/L3/handoff/<日期>-<客户端>.md`，**永久**、永不注入 |
| **T1** | 从 L3 **派生**出来的常驻视图，不另存一份 |
| **不写会怎样** | 等于没发生：L3 没有、T1 不变、她下次接不上 |

## 3. T1（常驻注入）

> **T1 = 上一次会话的全部 handoff（按主题 ≤3 条）＋ 所有 open 条目（≤3 条，独立于替换）**

- **替换单位 = 「上一次会话」整批**，不是"一条换一条"；
- 每条带**时间戳**；超过 **3 天**在注入时标 `[这条有点旧]`（只标，不删）；
- **open 独立**：不参与替换，只有写 `closing` 才退出；open 满 3 条 → 报旗；
- **注入顺序**：open 在前（未解决的事优先），普通条目按时间倒序；
- **只在工作 / 完整投影注入**（日常不注入：2026-10-27 maker 定，日常只聊天）；

## 4. T2（按主题唤起）

- 落点：L2 关键词层，新类型 **`过程`**；关键词 = 做这事的主题（"第1期""开场""扩散模型"）；
- 触发：**主题命中才注入**；单条 ≤150 token；同类 ≤6 条，超了合并成"我在这类事上容易卡：…"；
- **过期按期数，不按天**：**连续 8 期未被命中 → 归档**（退出 T2，只留 L3）；
- 进 T2 的时机：T1 到期退出时**自动提炼**（`handoff.py promote`）——条目必须带 `主题：`，否则只留 L3；提炼幂等（`_promoted.json` 记账）。

## 5. 出口三条

| 信号 | 动作 |
|---|---|
| 产物被取代（第二版覆盖第一版） | 旧条标 `superseded`，立刻退出 T1/T2 |
| 悬念解决 | 写 `closing`，该 open 条转 `closed`，走正常降级 |
| 同类卡点出现第 2 次（跨期） | **够 L1 双证据** → `l1.py propose`："她学会的事"由此长出 |

## 6. 预算与报旗

- T1：≤3 条 × 80 汉字 ≈ **400–500 token 封顶**，不随作业次数增长；
- T2：命中时单条 ≤150 token；
- 工作投影：**0**；
- 报旗：① open 满 3；② 连续 3 次都写"还没想明白"（防表演式反省）；③ 连续 3 次都是 `—`（防敷衍，只报不逼）。

## 7. 明确不做

- ❌ 全量思考过程注入（3k–15k token，会挤爆人格块）
- ❌ 自动化"总结刚刚的对话"（会编）
- ❌ 替她写过程（违反 B1：不能认领别人的事）
- ❌ "清理"= 删档（**清理只表示退出常驻；L3 永久**）

## 7.5 轮转（2026-10-28 增补 · 会动文件，但不删内容）

> 之前"永久"意味着活跃区无限增长，T1 每次要解析全部历史。现在加**轮转**：
> **活跃区只留最近 3 天 + 所有 open；其余移档；30 天前的月份压月包。**

| 项 | 规则 |
|---|---|
| 活跃期 | **3 天**（`handoff.py rotate --days 3`） |
| open 例外 | **永不移走**（没关的事不能被归档） |
| 归档位置 | `handoff/归档/<YYYY-MM>/`（按月） |
| 备份期 | **30 天**：超过的月份压成 `归档/<YYYY-MM>.zip`（带 sha256，记 `归档/_归档.json`） |
| 是否删除 | **不删**。压缩≠删除；内容仍在 zip 里 |
| 时机 | **收尾自动跑**（`workbench.py render`） |
| 谁能搜到 | `l3.py grep` / `recall` 走全目录（含归档）；**T1 只读活跃区** |
| 不归它管 | `_待写入-*` 草稿、`_closings/`、`_模板.md` |

**目的不是省盘**（按现在速度十年约 4 MB），是**把每次解析/注入的范围锁住**，并让 `_状态.md` 不再无限长。
