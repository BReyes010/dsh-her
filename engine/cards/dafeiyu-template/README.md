# 示例角色模板（开源默认卡）· 说明

这是「人格四层」的**可发布默认卡**。它带**空记忆**，你可以从零开始养，也可以改成人格完全不同的角色。
本目录里的所有文件都可以改；改动不影响任何现役角色。

---

## 一、四层是什么

| 层 | 放什么 | 文件 | 谁能改 |
|---|---|---|---|
| **L0 内核** | 她是谁：身份、动机、性格、底线 | `persona.md` | 只有你（maker） |
| **L1 自我认知** | 她自己总结出的行事原则（≤10 条，候选→生效→固化） | `../memory/<套件>/l1.db` | 她自己提，你签字 |
| **L2 记忆** | 她经历过什么、学到什么 | `../memory/<套件>/memory.db` | 她自己提，你签字 |
| **L3 日志** | 原始流水：每期成稿/复盘/handoff | `../memory/<套件>/L3/` | 只追加，**永不注入** |

一句话：**内核是"她是谁"，记忆是"她经历了什么"，日志是"当时到底怎么发生的"。**

---

## 二、三个概念，先分清（最容易混）

| 概念 | 是什么 | 例子 |
|---|---|---|
| **场景 / 投影** | 一个**方向**：决定装哪些技能、哪些记忆 | 日常对话、工作 |
| **技能** | 某个方向下的**具体能力规范** | **口播**：说话样本、风格规范、TTS 读法 |
| **记忆标签** | 一条记忆**谁能看见** | `scene = 通用 / 日常 / 工作` |

**关键：口播不是一个场景，它是「工作区」里的一个技能。**

```
工作区（area = 工作）
└── 技能：口播   ← scenes/口播/ 下的 work.md + tech.md
```

所以「工作投影」= 内核 + 工作区里**你选中的技能**（现在是口播）+ 通用/工作记忆。
以后想加"直播""写作""客服"，就各加一个技能目录，再在 `card.json` 里声明一条 scene —— **不要往内核里塞**。

## 三、三种加载方式

| 方式 | 是什么 | 装什么 |
|---|---|---|
| **完整模式** | **整个角色** | 内核 + 全部技能 + 全部记忆 + 交接单 |
| **工作模式** | 工作方向的投影 | 内核 + 口播技能 + 通用/工作记忆 |
| **日常模式** | 聊天方向的投影 | 内核 + 常驻记忆 |

三者内核是**同一份** `persona.md`；差别只在"装多少"。生成命令：

```powershell
python 脚本\make_mode_pack.py            # 出三个 txt 到 启动包/
python 入口\her-host.py --print 完整      # 或者直接打印
```

---

## 四、记忆标签怎么影响注入

| 标签 | 完整模式 | 工作模式 | 日常模式 |
|---|:--:|:--:|:--:|
| 常驻层（不限场景） | ✅ | ✅ | ✅ |
| `scene=通用`（跨场景事实） | ✅ | ✅ | ✅ |
| `scene=工作` | ✅ | ✅ | ❌ |
| `scene=日常` | ✅ | ❌ | ✅ |

写记忆时 `scene` **必须显式写**，不许靠缺省——缺省会变成"通用"，然后哪都出现。

## 五、本目录有什么

```
dafeiyu-template\
├── README.md              ← 本文件
├── card.json              ← 卡声明：id / 场景 / 技能 / 记忆套件
├── persona.md             ← L0 内核（模板版，可以整份改成别的角色）
└── scenes\
    └── 口播\               ← 示例技能：口播
        ├── work.md        ← 口播投影：样本、风格规范、被质疑时怎么办
        └── tech.md        ← 口播技术规范：数字读法、标点、句长（给 TTS 用）
```

配套的记忆套件在 `../memory/dafeiyu-template/`（空库 + L3 骨架）。

## 六、怎么加一个新技能（示例：直播）

1. 建 `scenes/直播/live.md`（直播专属规范：开场、节奏、弹幕应对）；
2. `card.json` 的 `scenes` 加一条：

```json
{
  "id": "直播",
  "label": "直播",
  "area": "工作",
  "skill": "直播",
  "files": ["persona.md", "scenes/直播/live.md"],
  "memory_scene": "工作"
}
```

3. 要单独出包，就在 `脚本/make_mode_pack.py` 加一个 job，并在 `her-host.py` 的 `build_persona` 里加载该文件。

**判断标准：换一个场景还成立吗？**
- 成立 → 写进 `persona.md`（底线、性格）
- 不成立 → 写进该技能的投影文件

## 七、别做的事

- 别把技能规范写进 `persona.md`——内核每轮都注入，塞技能会让聊天带上工作腔；
- 别让日志（L3）进上下文——它是给排查用的，不是给她读的；
- 别手改 `memory.db`——记忆走脚本（`脚本/memory_db.py`），要签字才生效。
