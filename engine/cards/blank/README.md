# 空白角色卡

## 怎么用

1. 复制这一整个目录：`cards/blank` → `cards/<你的角色 id>`
2. 改 `card.json` 里的 `id`、`name`、`memory_id`（三处要一致）
3. 复制 `memory/blank` → `memory/<你的角色 id>`
4. 填 `persona.md`
5. 注册：在 `cards/_registry.json` 与 `memory/_registry.json` 里加条目（或跑 `python 脚本/new_card.py`）

## 为什么是空的

示例卡里每句话都在教你怎么写——但也会让每个新角色长得像示例。
这张卡只有结构和提示，**一个字的人设都没有**。
